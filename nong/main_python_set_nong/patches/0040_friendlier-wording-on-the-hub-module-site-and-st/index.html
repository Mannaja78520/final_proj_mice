Timing

Show speed °/s per sequence
Servo max °/s
time between keyframes = biggest joint change ÷ show speed. Servo max is the physical limit (MG90S ≈ 400 °/s): each keyframe has a minimum time = change ÷ max — you can always make a move slower, but never faster than the servos can really go, so the arm always reaches the pose. The firmware enforces the same rule (max_dps).

Model (STL + texture)

Export STL from SolidWorks (mm) into models/ and press ⟳, or pick a file here and press Import (also accepts PNG/JPG textures — draw a face or pattern in any paint program and import it). Assign a shape and/or a texture per body part — the STL's real size sets the rig lengths automatically, and the yellow joint balls + bones stay visible so you always see the joints. If the STL origin doesn't match, use the rot / off / scale boxes under the part.

Clothes / add-ons

extra STL pieces (shirt, hat, decorations) layered over any body part — they follow that part's movement and never replace it.

Rig setup (match the 3D model to your robot)

zero° = the joint angle where that joint is drawn straight (arm along the body). It is just a reference — the normal value is 90 (the neutral pose), and you do not need 0 or 180. Only change it if at 90° your real arm is not straight: move the model's sliders to match the real robot, then type those angles as the zeros. axis = roll/pitch/yaw (which way it turns); inv flips the direction.
min/max = each joint's real travel in JOINT degrees — a universal joint can't reach 0–180 (default 30–150); the servo still runs 0–180 via the gear (12:13). Dragging respects these. These match the module and can be pushed to it.
