Timing

Show speed °/s per sequence
Servo max °/s
°/s

Studio plans at 60 °/s. Connect to read the robot's own limit. A saved change needs a restart.

time between keyframes = biggest joint change ÷ show speed. Three things can make a move longer than that, and the move's own line says which one did it: Servo max, the physical limit (MG90S ≈ 400 °/s); Peak speed limit, the safety cap — a move eases in and out, so its peak is about 1.6× its average and the cap bites at roughly ⅔ of this number (at 60 °/s, Show speed above ~38 °/s changes nothing); and the 80 ms shortest-move floor. You can always make a move slower, never faster than the servos can really go, so the arm always reaches the pose. Raising the peak limit makes moves faster and can cause harder impacts. Do not raise it while a joint loses torque.

Model (STL + texture)

Export STL from SolidWorks (mm) into models/ and press ⟳, or pick a file here and press Import (also accepts PNG/JPG textures — draw a face or pattern in any paint program and import it). Assign a shape and/or a texture per body part — the STL's real size sets the rig lengths automatically, and the yellow joint balls + bones stay visible so you always see the joints. If the STL origin doesn't match, use the rot / off / scale boxes under the part.

Clothes / add-ons

extra STL pieces (shirt, hat, decorations) layered over any body part — they follow that part's movement and never replace it.

Build it from a URDF (instead of placing every STL by hand)

A STEP file cannot be opened in a browser, and an STL on its own does not say where the part belongs — which is why a dragged-in part lands in the middle and has to be nudged into place. A URDF carries the position, the turn, the size and which part hangs off which, so importing one fills those boxes in for you.
From SolidWorks: use the sw2urdf add-in (Tools ▸ Export as URDF). It writes a .urdf file and a meshes folder — import the STL meshes above first, then the .urdf here.

Rig setup (match the 3D model to your robot)

zero° = the joint angle where that joint is drawn straight (arm along the body). It is just a reference — the normal value is 90 (the neutral pose), and you do not need 0 or 180. Only change it if at 90° your real arm is not straight: move the model's sliders to match the real robot, then type those angles as the zeros. axis = roll/pitch/yaw (which way it turns); inv flips the direction.
min/max = each joint's real travel in JOINT degrees — a universal joint can't reach 0–180 (default 30–150); the servo still runs 0–180 via the gear (12:13). Dragging respects these. These match the module and can be pushed to it.
Shrug linkage (4-bar). One servo lifts both shoulders, but a 4-bar does not lift them by the same amount, and the ratio changes across the travel — so the preview cannot just rock a bar. Measure it once: set SHRUG to a few angles and note how far each shoulder actually rose, in mm, up positive. Leave the box empty and the preview keeps the old symmetric rock.

Servo offset — one joint at a time

A servo horn only fits back on in whole teeth, so a joint is often a few degrees out even when everything else is right. Nudge the joint here until it looks straight: − and + move it by 0.5°, or type a number. 0 clears that joint.
The arm moves as you press, and the robot remembers this by itself. It only shifts where that joint sits — every pose and sequence you have saved keeps working. Set zero, on the Robot tab, does all ten at once instead.
