🎮 All-Jao Games — มินิเกมและระบบแจกของรางวัลอัตโนมัติ

ชุดมินิเกมสำหรับจัดกิจกรรมงานอีเวนต์ (ตู้คีบ, จับคู่การ์ด, ตอบคำถาม, วงล้อเสี่ยงโชค) เชื่อมโยงกับเซิร์ฟเวอร์ Mice Hub และผูกเข้ากับตู้กาชาปองแจกของรางวัลอัตโนมัติ

1 การเปิดเล่นเกม (Open Games)
ทำอย่างไร: กดปุ่ม Open in a new tab ↗ หรือเล่นผ่านกล่องในหน้าเว็บ
ตั้งแล้วเกิดอะไรขึ้น: Hub จะสั่งเริ่มโปรเซสเกมฝั่ง Python อัตโนมัติ (/api/all-jao/start) และเสิร์ฟหน้าจอเกมพร้อมเล่นทันที
2 เชื่อมต่อตู้แจกของรางวัล (Prize Binding)
ทำอย่างไร: ไปที่หน้า Prize machines ในหัวข้อ Games that give a prize เพื่อเลือกว่าเกมไหนให้รางวัลช่องใด
ตั้งแล้วเกิดอะไรขึ้น: เมื่อผู้เล่นทำคะแนนถึงเกณฑ์ ตู้กาชาปองจะหมุนจ่ายของรางวัลโดยอัตโนมัติทันที พร้อมแจ้งจุดรับของรางวัลบนหน้าจอ
3 สิทธิ์ความปลอดภัย (Venue Security)
ทำอย่างไร: หากเปิดเล่นจากเครื่อง PC ของบูธ ไม่ต้องล็อกอิน / หากเข้าผ่าน WiFi วงนอก ต้องล็อกอิน Admin
ตั้งแล้วเกิดอะไรขึ้น: ป้องกันบุคคลภายนอกที่เชื่อมต่อ WiFi ในงานแอบสั่งรันโปรแกรมบน PC หรือแอบสั่งหมุนของรางวัล

No hub sign-in needed on this PCnew

The games have their own login, so opening them on the PC that runs Mice asks for nothing. Opened from another device on the network, the hub asks you to sign in first, so nobody on the venue WiFi can start programs on this PC.

A win gives a real prizenew

Played inside the hub, a win in the wheel, claw, quiz or memory game can make a prize machine give a prize and tells the player where to collect it. Which result gives what is set on Prize machines ▸ Games that give a prize.
