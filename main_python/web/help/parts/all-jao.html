🎮 All-Jao Games

All-Jao is the event organiser this project is built for. Their games — claw machine, matching, quiz and wheel of fortune — run beside Mice on the same PC, and this page opens them.

No hub sign-in needed on this PCnew

The games have their own login, so opening them on the PC that runs Mice asks for nothing. Opened from another device on the network, the hub asks you to sign in first, so nobody on the venue WiFi can start programs on this PC.

A win gives a real prizenew

Played inside the hub, a win in the wheel, claw, quiz or memory game can make a prize machine give a prize and tells the player where to collect it. Which result gives what is set on Prize machines ▸ Games that give a prize.
