🎁 Prize machines — gachapon (เครื่องแจกของรางวัล / กาชาปอง)

เครื่องแจกของรางวัลอัตโนมัติแบบ Revolver Carousel 4 ช่อง พร้อมระบบ 4-Phase Safety Centering หยุดกึ่งกลาง Hall เซนเซอร์ 100% และระบบ Auto Detect ปรับจูนตามมวลของรางวัล

📐 1. สถาปัตยกรรมล้อหมุน 4 ช่อง (Revolver Mechanism)

หมุนทิศทางตามเข็มนาฬิกา (CW, dir: 1)
🟢 Continuous Vending (โหมดแจกปกติ: drop: 1)

เมื่อมีแคปซูลบรรจุพร้อมทั้ง 4 ช่อง การแจกของแต่ละครั้ง หมุนเพียง 1 แม่เหล็ก (90° / 1 ช่อง) แคปซูลในช่องถัดไปจะหล่นลงรางทันที ทำงานรวดเร็ว กระชับ ไม่เสียเวลาหมุนฟรี

🔵 Initial Prime Mode (โหมดโหลดตู้ครั้งแรก: drop: 2)

ตามระยะใน CAD ระหว่างจุดรับของ (ช่อง 2) กับปากรางปล่อย (ช่อง 4) ห่างกัน 180° (2 ช่อง) ใช้เฉพาะตอนเริ่มโหลดลูกแรกเข้าตู้ว่างให้พร้อมแจก

💡 ฮาร์ดแวร์: บอร์ด ESP32 คุม H-bridge 2 ขา (GPIO 25 & 26, Drive2pin), เซนเซอร์ Hall GPIO 33 (Active-Low), มอเตอร์มี Schottky Diode (0.187V drop) กันไฟย้อน

🔄 2. วงรอบการแจกของ 4 ขั้นตอน (4-Phase Safety Settle Cycle)

ออกแบบพิเศษป้องกันของติดคาปากราง (Dual-Rocking Agitation) และดูดกลับเข้ากึ่งกลาง Hall แม่นยำ 100%

Phase 1 180 ms
⏩ Forward Overshoot

หมุนเลยปากรางปล่อยช้าๆ (ความเร็ว overshoot_speed: 380) เพื่อให้แรงโน้มถ่วงเริ่มดึงแคปซูลให้ลื่นไหลลงราง

Phase 2 250 ms
🔁 Reverse Agitation

โยกถอยหลังข้ามแม่เหล็กไปอีกฝั่ง (ความเร็ว return_speed: 360) เขย่าสะบัดให้แคปซูลที่ติดหลุดลงไป แล้วหยุดพัก 60 ms ตัดแรงเฉื่อย

Phase 3 Micro-Step
🎯 Dead-Center Alignment

ย่องก้าวสั้นๆ (15 ms ที่ center_speed: 260) เข้าหาแม่เหล็ก พอเซนเซอร์แตะขอบ จะแทงเข้า Sweet Spot 18 ms แล้วล็อกเบรกตรงกลางทันที

Phase 4 5,000 ms
⏸️ Observation Pause

หยุดนิ่งตรงกลาง 5 วินาที (ปรับลดได้ 2s/5s) เพื่อให้แอดมินหรือผู้รับของมองเห็นสถานะของหล่นชัดเจน ไฟ at_hall ขึ้นเขียวเสถียร 100%

⚙️ 3. ตารางพารามิเตอร์ทุกตัว ทุกจุด ทุกการตั้งค่า (Parameters Reference)

Key (GCFG) ชื่อภาษาไทย ค่ามาตรฐาน ช่วงค่าที่ตั้งได้ หน้าที่เชิงกลและผลลัพธ์
drop จำนวนช่องที่หมุนปล่อย 1 1 - 64 1 สำหรับการแจกของปกติเมื่อล้อเต็ม, 2 สำหรับโหลดลูกแรกตอนตู้ว่าง
intake หน่วงเวลารอของหล่นลงช่อง (ms) 300 0 - 5000 หยุดรอให้แรงโน้มถ่วงดึงลูกจากท่อด้านบนตกลง Slot 2 ให้สนิทก่อนเริ่มหมุน ป้องกันลูกติดขัดหรือตกไม่ทัน
speed ความเร็วหมุนเดินทาง 500 50 - 1023 ความเร็วในการหมุนระหว่างช่อง (PWM duty: 500 ≈ 49% power) นุ่มนวล ไม่กระชาก
overshoot ระยะเวลาเลยปากราง (ms) 180 0 - 3000 เวลาที่ปล่อยให้หมุนเกินจุดจ่ายของช้าๆ เพื่อให้ของตกลงราง
overshoot_speed ความเร็วตอนเลยปากราง 380 50 - 1023 ความเร็วช้าพิเศษใน Phase 1 ป้องกันของกระเด็น
return ระยะเวลาโยกถอยหลัง (ms) 250 0 - 3000 เวลาที่หมุนถอยหลังเพื่อเขย่าคลายของที่อาจติดขอบราง
return_speed ความเร็วตอนโยกถอยหลัง 360 50 - 1023 ความเร็วตอนถอยหลังเขย่าใน Phase 2
center_speed ความเร็วคลานเข้าเซนเซอร์ 260 50 - 1023 ความเร็วย่องแบบ Micro-Step ใน Phase 3 เพื่อหยุดตรงกลางพอดี ไม่เลยขอบ
pause เวลาหยุดสังเกตของ (ms) 5000 0 - 30000 เวลาหยุดนิ่งที่จุดกึ่งกลาง (5 วินาที) ก่อนจบสถานะ ปรับเป็น 2000 ได้ถ้าต้องการไวขึ้น
slots จำนวนช่องบนล้อ 4 1 - 64 จำนวนหลุมใส่แคปซูลของล้อหมุน (ตามโมเดล 3D/CAD ปัจจุบันคือ 4 ช่อง)
magnets จำนวนแม่เหล็ก 4 1 - 64 แม่เหล็กที่ฝังใต้ช่อง (ต้องเป็นจำนวนเท่าของ slots)
timeout เวลาแจ้งเครื่องติด (ms) 5000 200 - 60000 หากหมุนแล้วไม่เจอแม่เหล็กในเวลานี้ มอเตอร์จะตัดเพื่อความปลอดภัย (แจ้งสถานะ jam)
debounce เวลาหน่วง Hall เซนเซอร์ (ms) 5 0 - 200 เวลากรองสัญญาณแม่เหล็กให้นิ่ง ป้องกันการนับเบิ้ลจากสัญญาณรบกวน
active_low ขั้วสัญญาณเซนเซอร์ 1 0 หรือ 1 1 = ดึง LOW เมื่อมีแม่เหล็ก (สำหรับเซนเซอร์ A3144 / US1881)

🧪 4. โหมดพิเศษและการใช้งานจริง (Special Modes & Tools)

⚡ Auto Detect Mass (`GCALIB`)

แก้ปัญหามวลของแต่ละชิ้นไม่เท่ากัน: เมื่อเปลี่ยนของรางวัลใหม่ (เช่น พวงกุญแจเหล็ก vs แคปซูลพลาสติกเบา) ให้กดปุ่มนี้ เครื่องจะหมุนสแกนหาขอบแม่เหล็กและวัดระยะเฉื่อยของมวลจริง แล้วคำนวณจุดหยุดกึ่งกลาง Hall พร้อมบันทึกลง NVS ให้อัตโนมัติทันที

คำสั่ง: GCALIB -> OK CALIBRATED span_ms=50
🧪 Machine Self-Test (`GTEST`)

ทดสอบเครื่องก่อนเริ่มงาน:
• Test 1 Pocket: หมุนทดสอบ 1 ช่องพร้อมตรวจเช็กการหยุด Dead-Center
• Test 4 Pockets: รันวนทดสอบรอบล้อทั้ง 4 ช่องต่อเนื่อง เพื่อยืนยันว่าทุกลูกหยุดตรงกลางแม่เหล็ก 100%

คำสั่ง: GTEST 1 หรือ GTEST 4
⚡ Force Drop (บังคับปล่อยเพื่อทดสอบ)

ทดสอบระบบได้ทุกสถานะ: สั่งหมุนปล่อยของ 1 ช่องพร้อมระบบ 4-phase ทันที แม้ในกรณีที่ไม่มีของ สต็อกเป็น 0 หรือปิดอีเวนต์อยู่ เหมาะสำหรับแอดมินหรือช่างทดสอบความพร้อมของกลไก

คำสั่ง: GDISPENSE FORCE <who>
Motor Diagnostic Pulse (GNUDGE)

ทดสอบสั่งหมุนสั้นๆ: ส่งสัญญาณ PWM และระยะเวลา ms เพื่อขยับมอเตอร์ดูความพร้อมของกลไก

คำสั่ง: GNUDGE <pwm> <ms>
🌀 Drain Machine (โหมดวนปล่อยจนของหมด)

วนปล่อยต่อเนื่องอัตโนมัติ: เครื่องจะแจกของทีละลูกต่อเนื่องตามลำดับ พร้อมรอบเขย่า 4-phase ในทุกลูก จนกระทั่งของในสต็อกหมดลง (Stock = 0) หรือกดปุ่ม ⏹️ Stop Drain เพื่อหยุดกลางคัน

คำสั่ง: GDRAIN [<max>] | STOP เพื่อยกเลิก
📊 หน้าเว็บ Real-Time Status & Tuning

บนหน้าเว็บ /app/gacha จะมีไฟสถานะสด:
• 🟢 Center: ล้อหยุดตรงกลางแม่เหล็กพอดี
• Phase: แสดงขั้นตอนปัจจุบัน [turning], [center], [pause]
• Pocket: ตำแหน่งช่องปัจจุบัน (เช่น P1/4)
• ⚙️ Tune: แถบปรับค่าความเร็ว/เวลาได้ทันที

Several machines

Add each machine with its board name, the kind it holds and where it stands. Machines with the same kind stand in for each other: when the one asked for is empty, the next one gives the prize and the robot tells the person where to go. Next to says which to try first. A machine next to it may hold a different kind: When it runs out, give instead (Kinds) names what a person gets in its place. its own page opens the machine's own settings (magnets, pockets until it falls, speed) from here.

Rules for an event

Per kind: how many there are and how many times one person may get one. People: a person's own limit or a special guest, by the name the face app knows. Give one anyway is for the admin: it works past the limits and is still counted. The rules can come from a Google Sheet with two tabs, items and people. Paste the sheet's link in the Google Sheet tab of the page; with the sheet's own script set up once (the steps are on that tab, in Thai) the hub also writes the sheet: the rules, any tab as a table, and a row per prize.
