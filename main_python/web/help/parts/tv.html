📺 TV Remote & Monitor — หน้าจอควบคุมสำหรับ Smart TV และมือถือ

หน้าเว็บควบคุมและตรวจสอบสถานะแบบบางเฉียบ (Thin Client) ออกแบบตามสถาปัตยกรรม Centralized Server ตัดการประมวลผล 3D Three.js ออก 100% ทำให้เปิดได้รวดเร็ว ลื่นไหล ไม่กินสเปก และไม่มีอาการค้างบน Smart TV หรือสมาร์ทโฟน

ผังเปรียบเทียบสถาปัตยกรรม Nong Studio (PC) vs TV Remote (Smart TV / Mobile) Infographic
1 ปุ่มควบคุมการเคลื่อนไหวหลัก (Play / Pause / Stop / Home)
ทำอย่างไร: กดปุ่มขนาดใหญ่บนหน้าจอ หรือใช้ปุ่มลูกศร/Enter บนรีโมททีวี
ตั้งแล้วเกิดอะไรขึ้น: • Play / Pause: สั่งเริ่มหรือหยุดการขยับท่าทางชั่วคราว
• Stop: สั่งหยุดหุ่นยนต์ฉุกเฉินทันที มอเตอร์จะล็อคตำแหน่งปัจจุบัน
• Home: คืนแขนและคอหุ่นยนต์กลับสู่ท่าเริ่มต้นที่ปลอดภัย (Neutral Pose)
2 รายการท่าทาง (Sequence Launcher)
ทำอย่างไร: เลือกท่าทางจากกล่องดรอปดาวน์ แล้วกด ▶ Play Sequence
ตั้งแล้วเกิดอะไรขึ้น: ระบบจะดึงไฟล์ท่าทางจาก Hub กลาง (`/api/list?kind=sequences`) และสั่งให้หุ่นรันชุดท่าทางนั้นทันที เจ้าหน้าที่หลังเวทีสามารถใช้มือถือกดเลือกโชว์ได้สะดวก
3 สั่งเสียงพูดด่วน (Quick Speech & Speak)
ทำอย่างไร: แตะปุ่มคำพูดยอดนิยม เช่น "สวัสดีครับ", "ขอบคุณครับ" หรือพิมพ์ข้อความในช่อง
ตั้งแล้วเกิดอะไรขึ้น: ส่งคำสั่งเข้าคิวเสียงกลาง (`/api/speak`) เสียงจะเปล่งออกจากลำโพงของหุ่นยนต์ Nong หรือลำโพงเวทีทันทีโดยไม่กระตุก
4 มอนิเตอร์ข้อต่อ 10 จุด (10-Joint Monitor Gauges)
ทำอย่างไร: ดูแถบวัดระดับองศาเซอร์โวด้านล่างหน้าจอ
ตั้งแล้วเกิดอะไรขึ้น: แสดงมุมองศาจริง (0° - 180°) ของข้อต่อทั้ง 10 จุด (ไหล่ ข้อศอก เอว คอ) แบบ Real-time ด้วย CSS Gauge เบาๆ แสดงผลอัปเดตแบบ 200ms โดยไม่ดึงภาระ GPU หรือ CPU ของทีวี

Decoupled Architecture: ป้องกันทีวีค้างได้อย่างไร?

ในสถาปัตยกรรมแบบเดิม หากเปิดหน้า 3D (Three.js) บน Web Browser ของ Smart TV หรือมือถือรุ่นเก่า เบราว์เซอร์จะต้องคอมไพล์ WebGL Shaders และรันลูปคำนวณ 60 รอบต่อวินาที ซึ่งชิปประมวลผลของสมาร์ททีวีไม่ได้ออกแบบมาเพื่อรองรับ ส่งผลให้เบราว์เซอร์ทีวีปิดตัวเองหรือเครื่องค้าง

ทีวีรีโมท (TV Remote) แก้ไขปัญหานี้โดย: 1. ย้ายการคำนวณทั้งหมดไปไว้ที่ Python Hub บนคอมพิวเตอร์ส่วนกลาง
2. ฝั่งหน้าจอทีวีส่งเฉพาะคำสั่ง JSON สั้นๆ ผ่าน REST API
3. การแสดงผลกราฟิกใช้เฉพาะ HTML5 & CSS3 พื้นฐาน ไม่มี Canvas 3D แม้แต่บรรทัดเดียว
4. น้ำหนักหน้าเว็บรวมไม่ถึง 25 KB โหลดเสร็จในเสี้ยววินาที

การควบคุมด้วยรีโมททีวี (Smart TV Navigation)
