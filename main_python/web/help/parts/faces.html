👋 FaceReg / Reconize — ใบหน้าและการทักทาย

เปิดโปรแกรมใบหน้า ตรวจว่าหุ่นรับข้อมูลได้ แล้วตั้งคำพูดและท่าทางเมื่อพบคน

เลือกหน้าที่ตรงกับงาน

เปิดหน้า Reconize ของ Mice หน้านี้มี 3 แท็บ ส่วนโปรแกรมจัดการใบหน้าจะเปิดผ่านปุ่ม Open Reconize

ต้องการทำอะไรเลือกแท็บทำอย่างไร / ผลที่ได้
เปิดโปรแกรมใบหน้าOpen itกด Open Reconize เพื่อเปิดโปรแกรม ใช้ Check it is running เพื่อตรวจว่าโปรแกรมทำงานหรือยัง
ตรวจการรับข้อมูลของหุ่นIs the rig following it?ดูสถานะตัวติดตามข้อมูล ถ้ายังไม่เริ่ม จะมีปุ่ม Start following Reconize
เปลี่ยนคำทักและท่าทางWhat the rig saysตั้งคำพูด ผู้พูด เวลาเว้นการทัก และพฤติกรรมแยกตามกล้อง แล้วกด Save
1. เปิดการทักทายและเลือกผู้พูด

ใน What the rig says เปิด Greet people the face app sees แล้วเลือก Speaker ว่าจะให้เสียงออกที่ไหน

ช่อง Polite word before a name เป็นคำเรียกนำหน้าชื่อ ส่วน If the rig is already talking or playing เลือก skip this hello เพื่อข้าม หรือ wait its turn เพื่อรอ

2. เขียนคำทักทายและเว้นระยะการทักซ้ำ

ตั้งเวลาใน Greet the same person at most once every เป็นนาที และเวลาของคนที่ยังไม่รู้จักเป็นวินาทีต่อกล้อง

ในส่วน When they arrive และ When they leave ใส่คำพูดแยกตามคนที่มาครั้งแรก กลับมาอีก และคนที่ยังไม่รู้จัก

{title} แทนคำเรียก และ {name} แทนชื่อ คนที่ยังไม่รู้จักไม่มีชื่อให้แทน ใช้คำทักทั่วไป เช่น “สวัสดีครับ ยินดีต้อนรับครับ”

3. เลือกพฤติกรรมและท่าทางของแต่ละกล้อง

ในหัวข้อ Cameras เลือกว่ากล้องนั้นจะทักตอนพบคน (says hello) บอกลา (says goodbye) หรือนับคนอย่างเดียว (only counts)

เลือก Move และหุ่นในช่อง on ของกล้องนั้น รายการท่ามาจากไฟล์ที่บันทึกไว้จริง ถ้าต้องการพูดอย่างเดียวให้เลือก none

ถ้ากล้องยังไม่ปรากฏ ใช้ Add a camera by name ชื่อกล้องต้องตรงกับข้อมูลที่โปรแกรมใบหน้าส่งมา

บันทึกและตรวจผล

กด Save ด้านล่างและรอข้อความยืนยันการบันทึก การเปลี่ยนค่ามีผลเมื่อระบบพบคนตามเงื่อนไขครั้งถัดไป Undo my changes โหลดค่าที่บันทึกไว้กลับมา

ถ้าต้องการประกาศเมื่อยอดคนถึงจำนวนที่กำหนด ใช้ Celebrations ส่วนคำเรียกเฉพาะบุคคลอยู่ใน Titles for particular people

ที่อยู่โปรแกรมภายนอกอ่านจาก config/partners.json

4. ระบบสีและการสืบทอดธีมแบบไดนามิก (Universal Dynamic Theme Sync)

หน้า Reconize สืบทอดธีมสีจาก Hub กลางอัตโนมัติผ่าน MiceThemeManager (เช่น โหมดมืด Midnight) ไม่บังคับแสดงผลพื้นหลังขาวจ้า แสบตา หรือกระพริบเปลี่ยนสี เมื่อผู้ใช้เปลี่ยนธีมใน Hub ทุกแท็บและแอปจะปรับสีตามทันทีแบบเรียลไทม์
