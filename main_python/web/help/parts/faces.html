👋 Reconize — the app that knows who is here

Reconize is a separate program that watches cameras and recognises people. It runs beside Mice on the same PC. This page is how you open it and how you choose what the rig says when it sees somebody.

What works today

Open Reconize starts it if it is not running and shows it in the page. Is the rig following it? says whether the rig is seeing people arrive. When it is not, Start following Reconize starts Reconize and the rig's own face helper together, in one press. Under the open button a line says whether the installed Reconize is the version Mice was tested with; a newer one is only pointed out, and everything keeps working as before.

What the rig says is where you choose the words. Nothing is said until you tick Greet people the face app sees and press Save. Saving asks you to sign in on the hub page first, because it changes what a robot says to a guest. The next person who arrives already gets the new words; nothing needs restarting.

  • The words. One line for each case: somebody's first visit today, somebody who already came today, and somebody it does not know. Write {title} where the polite word goes and {name} where the name goes. Somebody it does not know is never called by a name, so only {title} works in that line, and the page refuses to save otherwise.
  • Cameras. Each camera that has seen somebody appears by itself. Pick whether it says hello, says goodbye or only counts, which speaker says it, and a saved move a robot plays with it. A camera you never set up only counts, so a new camera never starts talking on its own. Open Its own words to give one camera different words.
  • Once per person. The same person is greeted at most once in the minutes you choose, whichever camera sees them. Somebody it does not know is greeted at most once per camera in the seconds you choose.
  • If the rig is busy. skip this hello drops it while the rig is talking or playing a show; wait its turn says it afterwards. A greeting never stops a show.
  • Celebrations. Said once a day when that many people have come today, by Reconize's own count. Each can play a move too.
  • Titles. Give a particular person their own polite word, such as อาจารย์, instead of the usual one.

If it says Reconize is not answering, start it with start.bat in its own folder and wait about fifteen seconds — it loads a face model before it answers anything, so not answering and not started look the same for those first seconds.

Where Reconize lives, and how to move it

Its addresses are written in config/partners.json — one entry for each outside program Mice follows. Change the address there and the button follows on the next refresh. Nothing is compiled in, so moving Reconize to another port or another PC costs one edit and no rebuild.

That same file is how the next outside program is added: one entry, no code. Each entry says where the app is, how to log in to it, where its events come from, and — just as important — what each of those sources cannot tell us, so the rig never promises more than it can see.

No password is kept in that folder, and none ever will be. Every file belonging to a tool is served to anyone who can reach the hub, with no login at all — so a password put there would be readable by everybody on the venue WiFi. Logins for Reconize live beside the hub's own password file instead, outside anything that is served.

We never change Reconize itself

It updates itself, often, and its updater throws away anything it finds that it did not write. So Mice never puts a file in its folder, never runs its updater, and never opens its database directly — reading that database while it is running would block its own writing. Everything goes through its web address, the same way any other program would talk to it.

Only answer when somebody is there

The Voice screen can be set to take questions only while somebody stands in front of a camera (in config/voice.json, presence, off at first). If Reconize is not running, or has no camera that can tell, questions are taken as usual: a broken camera never makes the rig deaf.

All of this is tested against stand-ins for Reconize and the robot, not yet with the real cameras at the lab.

Each of those arrives as its own small change, and the plan for all of it is docs/system_integral.html, beside this project's own plan.
