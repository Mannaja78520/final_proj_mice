Transports — the same features on every link

Text commands and SD file transfer work identically on all three. The difference is reach and speed, never capability.

LinkReachesNotes
WiFiAny module on the network, from any deviceWebsite + HTTP API. Fastest for whole-file transfer. Falls back to its own hotspot.
USBThe board on the cable115200 baud. No network needed. Shared by the hub, so several pages can use one cable.
RS485Every module on the busFramed #id … / @id …. Works through a dongle or through another module's USB port.

Board numbers — find and fix two boards sharing onenew

On the hub's Modules tab, the Board numbers card checks one cable. Pick the cable and press Check numbers. It lists any boards that share a number on that cable and, when some boards are plugged into other boards, who is plugged into whom. Checking changes nothing. If boards share a number, press Give them new numbers… and confirm: each board but one gets a free number, and the hub checks again. Changing numbers needs the same sign-in as flashing. Turn on Show technical details to see each board's permanent chip and its path (for example >100>200>7).

A cable holds up to 247 boards. For more, use more cables, or plug boards that have a second link into the bus (up to 3 in a row). The same board seen on USB, RS485 and WiFi is still one row on the Modules tab.
