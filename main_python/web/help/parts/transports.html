Transports — the same features on every link

Text commands and SD file transfer work identically on all three. The difference is reach and speed, never capability.

LinkReachesNotes
WiFiAny module on the network, from any deviceWebsite + HTTP API. Fastest for whole-file transfer. Falls back to its own hotspot.
USBThe board on the cable115200 baud. No network needed. Shared by the hub, so several pages can use one cable.
RS485Every module on the busFramed #id … / @id …. Works through a dongle or through another module's USB port.
