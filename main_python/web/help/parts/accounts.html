🔑 Accounts and passwords

A new hub and every board start with two logins: super_admin and admin, both with the password admin123. These are defaults everybody knows, so change them.

Change your own password or namenew

Log in, then press My account in the login box. Type your current password and a new one (8 characters or more), or a new username. While an account still uses admin123, the login box says so on every page.

One login for the hub, Nong Studio and the robotsnew

Log in once, on the hub page or in Nong Studio, and both are logged in. When a robot on WiFi asks for its own login, the hub first tries the account you logged in with, then the logins robots ship with (listed in config/board_logins.json). A robot with none of those accounts says so, and still works over its USB or RS485 cable.

Robot home and show neutral are two different posesnew

Home is where the robot goes when it powers on and when you press Home. Set it in Nong Studio's Robot card with Keep this as robot home, in the Setup table's start° column, or on the robot's own page (⚙ Open module): jog the arm, then Keep where the arm is now as home, or type the start angles and press Save these start angles. Neutral is the rest pose of a show and stays in Studio: Keep this as neutral never changes the robot.

A frozen Studio page stops the robotnew

When the hub plays a show from Nong Studio and the Studio page freezes, the hub stops the show and the robot within a few seconds, and says why. Hiding the tab or closing Studio on purpose still lets the show carry on by itself. Studio beats POST /api/play/beat every second while on screen; a watched show silent for 4 s is stopped (ShowPlayer.BEAT_TIMEOUT).

See distances on the robot in Studionew

Press 📏 Distances under the view buttons in Nong Studio's 3D view, or hold the D key, to see dashed lines with the length in mm: each elbow to its hand, elbow to elbow and hand to hand. They follow the pose as you move it. The pairs are listed in nong/main_python_set_nong/web/distances.json; add a pair there to measure something else.

Open one app on its ownnew

Each app (Nong Studio, Voice, Faces, Camera…) can open in its own window without going through the hub page. Double-click its shortcut in the Apps folder next to MiceHub.exe. If the hub is not running yet, the shortcut starts it too; if it is, the same hub is used, so the robot cables are still shared. Shortcut = MiceHub.exe --open <app id>. Make the shortcuts again after adding an app: python tools/make_app_shortcuts.py (add --desktop for the Desktop). The browser used for the window is listed in config/app_window.json.

A move's music list stays opennew

Press ♪ on a move to choose a track and its volume. The list now works whenever the robot is connected, with or without live, and clicking it no longer closes it before you can choose.

The Zero position lock uses your hub loginnew

In Nong Studio the Zero position card opens with the same user name and password as the hub (for example admin / admin123). The old browser-only password is gone. On the robot's own page the zero card is under Setup, after logging in.

Studio says when its joint limits differ from the robot'snew

When Studio connects it compares its joint limits with the robot's. If they differ, the arm would stop short of the preview, so Studio says which joints and offers Use the robot's limits or Send Studio's limits to the robot.

A looping show goes back to its start at the robot's pacenew

With loop on, the end of the show is followed by the move back to the first pose, timed like any other move, so the preview and the real arm stay together round after round. The hub also waits as long as the robot says a move really takes.

Delete a saved YAMLnew

Pick it in the saved list and press 🗑 Delete. It is moved to sequences/.deleted on this PC, so a mistake can be put back. To edit one, press Load for editing, change it, and 💾 Save.

A frozen Studio page reports itselfnew

If the Studio page stops for more than 1.5 seconds, it sends the hub a short report of what was running (playing, live, monitor, slow robot calls). It appears with the other reports on the hub.

A USB-RS485 adapter needs no bus id typednew

In Nong Studio pick + USB / RS485 (shared), choose the port and press Connect. If nothing answers on the cable itself, Studio asks the hub which robot is on the bus behind it and uses that one.

super_admin looks after everyonenew

Only super_admin can add or remove accounts, rename anyone, and set a new password for anyone (✎ and 🔑 beside each name on the hub's Accounts card). The last super_admin can never be removed, so the accounts can always be managed. To give someone else the same rights, pick super_admin beside Add when you create their account.
