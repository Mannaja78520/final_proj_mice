Several people can watch at once

The board itself can only be read by one thing at a time, and that is the hardware rather than a limit anybody chose: it has a single frame buffer, and taking a frame reclaims the one already on loan, so two streams would tear each other's pictures. The hub therefore holds one connection to each camera and feeds every viewer from it. Open this page on as many screens as you like.
