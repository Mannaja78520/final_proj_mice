ESP32 camera — watch a board's camera on its own

Every camera board the hub can reach, in one place, without opening a module's whole website to find its Camera card.

It is called ESP32 camera because that is all it can show. The list is built from modules of type cam — the ESP32-CAM boards. A webcam plugged into this PC is not one of them and will not appear here.

Several people can watch at once

The board itself can only be read by one thing at a time, and that is the hardware rather than a limit anybody chose: it has a single frame buffer, and taking a frame reclaims the one already on loan, so two streams would tear each other's pictures. The hub therefore holds one connection to each camera and feeds every viewer from it. Open this page on as many screens as you like.

A slow viewer — a phone on poor WiFi — is given the newest frame each time it is ready for another, so it drops frames rather than holding anyone else back. If a camera stops answering, the live view says so instead of leaving an old picture on screen pretending to be now.

A camera has to be on WiFi to be seen

Pictures do not travel down a USB or RS485 cable: those carry one line of text at a time, and a JPEG is not that. A camera reachable only on a cable is listed, and says so, with its picture controls switched off. Its settings still work over the cable.

Settings

Every setting the sensor has — brightness, contrast, saturation, white balance, exposure, gain, effects and the correction switches — lives on the module's own page under Settings, grouped, with one control to put everything back to default. The list is built from what the board reports, so it is always what that board can really do.

Two things it will tell you rather than hide. A setting this sensor does not have is shown greyed with this sensor does not have it — the OV2640 has no sharpness, for instance. And a setting that only applies while another is off (exposure time needs auto exposure off, gain needs auto gain off) says which one to turn off.

There is no autofocus. The OV2640 on these boards is fixed focus, so there is nothing to switch on and no control for it.
