📍 แท็บ 1: Pose — ปรับแต่งท่าทาง เซอร์โว 10 จุด และทิศทางมือ

ใช้สำหรับจัดท่าทางของหุ่นยนต์ Humanoid ท่อนบน โดยมีเซอร์โวควบคุม 10 ข้อต่อหลัก:

  • L/R shoulder pitch & roll: ข้อต่อไหล่แบบ Universal Joint สองตัวขับเคลื่อนมุมก้ม-เงย และกาง-หุบ (เซอร์โว PDI-1181MG หมุนได้กว้าง 270°)
  • L/R elbow pitch & roll: ข้อต่อข้อศอกสองตัวขับเคลื่อนการงอแขนและการหมุนท่อนแขน (เซอร์โว MG90S 180°)
  • Waist (เอว): เซอร์โว TianKongRC 35kg พลังแรงบิดสูง หมุนเอวซ้าย-ขวา 270°
  • Shrug (ยักไหล่): กลไก 4-bar linkage ยกสะบักไหล่ทั้งสองข้างขึ้นพร้อมกัน (~6°)
  • Hand Orientation: เลือกระหว่าง L/R on edge (สันมือตั้ง), palm down (คว่ำมือ), palm up (หงายมือ) เพื่อล็อกแนวหมุนของข้อมือให้สวยงามตามธรรมชาติ

⏱️ แท็บ 2: Sequence — การคำนวณเวลา ความเร็วปลอดภัย และจัดการ SD Card

ควบคุมพฤติกรรมการเล่นท่าทางตามหลักฟิสิกส์จริงของฮาร์ดแวร์:

  • สูตรคำนวณเวลาอัตโนมัติ: Time = Biggest Joint Change ÷ Servo Speed (°/s) ระบบจะหาข้อต่อที่ต้องหมุนไกลที่สุด และคำนวณเวลาให้พอดีกับความเร็วสูงสุดที่ตั้งไว้
  • Safe Speed Cap (ความเร็วสูงสุดปลอดภัย): ค่าเริ่มต้นจำกัดที่ 375–400°/s เพื่อป้องกันไม่ให้เซอร์โวกระชากตัวหุ่นยนต์จนโครงสร้างปริแตก
  • Robot SD Card File Manager: ดูรายการไฟล์ YAML ทั้งหมดที่อยู่ในการ์ด SD ของบอร์ด ESP32 สามารถกด Upload, Download กลับมาแก้ หรือ Delete ทิ้งได้โดยตรง

🎬 แท็บ 3: Video — แปลงวิดีโอคลิปคนเต้นเป็นท่าทางหุ่นยนต์อัตโนมัติ

ฟีเจอร์ AI Motion Capture จากคลิปวิดีโอ:

  • แหล่งวิดีโอที่รองรับ: วางลิงก์ YouTube, Google Drive แบบสาธารณะ, Dropbox หรือ Direct Video Link (MP4/WebM)
  • Skeleton Extraction: สกัดจุดข้อต่อกระดูกของมนุษย์ในคลิปวิดีโอ แปลงเป็นมุมองศา Servo 10 ตัวที่หุ่นยนต์ Nong สามารถทำตามได้จริง
  • Mirror Switch: เลือกว่าจะให้หุ่นขยับแบบกระจกเงา (Mirror) หรือทิศทางเดียวกับคนในวิดีโอ

🎭 แท็บ 4: Shows — จัดรายการแสดงต่อเนื่องหลายท่าทาง (Show Playlist)

สร้างการแสดงแบบสมบูรณ์ที่เล่นหลายๆ ท่าต่อกันโดยไม่มีช่องว่างสะดุด:

  • เรียงลำดับการแสดง: เช่น greeting.yaml → หยุดพัก 1.5 วินาที → wai.yaml → dance.yaml → byebye.yaml
  • แนบไฟล์เพลง (Show Music): อัปโหลดไฟล์ MP3/WAV ลงบอร์ด หุ่นยนต์จะเริ่มเล่นเพลงพร้อมกับขยับท่าทางไปพร้อมกันอย่างตรงจังหวะ
  • Save to robot (.show.yaml): บันทึกชุดการแสดงลงบอร์ด ESP32 เมื่อเสียบปลั๊ก หุ่นสามารถกดปุ่มเล่นโชว์ทั้งหมดได้ทันทีโดยไม่ต้องมีคอมพิวเตอร์เปิดค้างไว้

🔌 แท็บ 5: Robot — จัดการการเชื่อมต่อฮาร์ดแวร์จริง และ Zero Calibration

ศูนย์ควบคุมการคุยกับหุ่นยนต์จริงผ่านสายและไร้สาย:

  • โหมด WiFi: พิมพ์ชื่อโฮสต์ nong.local หรือ IP เพื่อสั่งงานผ่านเครือข่าย
  • โหมด USB / RS485 (Shared): แชร์พอร์ต COM เดียวกันผ่าน MiceHub ทำให้หน้า Studio และหน้าโมดูลเปิดคุยกับบอร์ดพร้อมกันได้โดยไม่แย่งพอร์ต
  • โหมด Dummy Follow: หากมีหุ่นจำลองบอร์ด mice_dummy (ใช้ Potentiometer แทนเซอร์โว) สามารถจับหุ่นดัดท่าด้วยมือจริง แล้วโมเดล 3D ใน Studio จะขยับตามแบบเรียลไทม์
  • Zero-Position Lock: ป้องกันคนเผลอกดรีเซ็ตตำแหน่งศูนย์ (Neutral 90°) ต้องกรอกรหัสผ่าน Admin จึงจะสามารถปรับแต่งค่าศูนย์ของมอเตอร์ได้

⚙️ แท็บ 6: Setup — สเปกโครงสร้าง Rig, มอเตอร์ และ CAD 3D Models

การปรับแต่งฮาร์ดแวร์เชิงลึก:

  • Servo Profiles: เลือกรุ่นเซอร์โวที่ประกอบจริง เช่น ไหล่ PDI-1181MG (270°), ข้อศอก MG90S (180°), เอว TianKongRC 35kg (270°)
  • Pinion / Gear Ratios: ใส่อัตราทดของเฟืองขับ เพื่อให้มุมองศาบนหน้าจอตรงกับการเคลื่อนที่จริงของข้อต่อกระดูก
  • 3D CAD Package (URDF Import): สลับการแสดงผลจาก Simple Shapes ทรงเรขาคณิตทั่วไป ไปเป็นโมเดลชิ้นงาน CAD เสมือนจริงที่วาดขึ้นจาก SolidWorks เพื่อดูรายละเอียดการประกอบ
