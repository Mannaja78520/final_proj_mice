Who can use this hub

      
…

      

        
        
        
        
        
      

      
A password is 8 to 32 characters with no spaces. Removing
        someone logs them out immediately. The last account cannot be removed —
        a hub nobody can log into has to be fixed by deleting its password file
        on the PC.

    


    
The first password is generated on the PC that runs the hub
      and written next to it, so it cannot be lost. It is never shown on a page.

  


  
  

    
🎨 Colour

    

    
Dark stays the default: a bright screen spills light into
      the show area. Adding another theme is one block in
      shared/web/themes.css — it appears here by itself.


    
🔧 How much to show

    
The Show technical details switch at the top of the
      page: addresses, cable ports and signal strengths — what you need
      the moment something is wrong, and noise the rest of the time. Names, types
      and module numbers are always shown.
