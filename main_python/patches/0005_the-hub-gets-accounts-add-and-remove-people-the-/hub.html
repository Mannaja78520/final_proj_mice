Who can use this hub

…
A password is 8 to 32 characters with no spaces. Removing someone logs them out immediately. The last account cannot be removed — a hub nobody can log into has to be fixed by deleting its password file on the PC.
The first password is generated on the PC that runs the hub and written next to it, so it cannot be lost. It is never shown on a page.

🤝 Which modules work together

Modules only link to modules in the same group. A group is your installation — put your modules in one and they find each other by themselves, even with no venue WiFi. Another company's modules standing in the same room cannot join yours, and yours cannot join theirs, because a module's own hotspot password is derived from its group name.

🔌 Modules plugged in by cable

…
each port shows its result the moment IT answers — real USB-UART ports take ~2 s; Bluetooth phantom ports are recognized by their device type and skipped without opening them. A probed module shows who it is + every RS485 module behind it. “auto-check” re-probes every 12 s while this page is visible — it costs almost nothing (the PC just waits on the port), but the port is briefly busy, so turn it off while connecting Nong Studio over USB.
