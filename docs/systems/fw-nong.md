# fw-nong

The nong (humanoid): 10 joints (8 arm + WAIST + SHRUG), poses, speed, limits.

## Rules and traps

- Angles are JOINT degrees. Gear, pulse range and servo travel are per joint,
  all in ONE field table (`fields_`): a new per-joint setting is a table entry,
  never a new array.
- Frames are 50 Hz from a `millis()` clock in `NongModule::loop`; the move is
  time-based (`nongmath::ease`), so a late frame is less smooth, never wrong.
- `link`/`peer` forwards each resolved pose to a partner board over RS485.
- `NongMath.h` is pure maths with native tests; every formula has an entry in
  `docs/ref_data.js` (`check_ref` fails without it).
