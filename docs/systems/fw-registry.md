# fw-registry

Registries: commands, modules, servos, amps, cameras, pins - and the generators that turn them into firmware tables.

## Rules and traps

- `config/amps.json`: no double quote or backslash in any text. The board
  builds AMP VALID's JSON by joining the strings, so one quote empties the
  whole Amplifier picker; `gen_tables.py` refuses it and `check_amp_kind`
  compiles and runs the generated table to prove the JSON parses.
- An amp's `to` names exactly the pins it wires: it is the line under each
  GPIO box that says which board the wire goes to (the lift's DAC-into-amp
  chain, A24-41).
- AMP VALID carries every amp in one reply, so each new amp makes it longer;
  it has to fit one RS485 line (fw-core) or a lift behind another board loses
  its Amplifier card. check_amp_kind fails first.
