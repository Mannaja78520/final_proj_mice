# hub-web

The pages the hub serves: Home/Modules, help, login, and their patch snapshots.

## Rules and traps

- `hub.html` is BUILT (A41-3): edit `main_python/web/home/` (template, one
  part per tab, `style.css`), then `python tools/build_web.py`. How:
  `docs/web_style.md`.
- `help.html` is BUILT too (A41-6): edit `main_python/web/help/` (template =
  sidebar + section order, one part per section, `style.css`, `search.js`).
  A new section is a part, a template line, a sidebar link and a by-task link.
- Home's script parts share ONE script in the order of `tools/web_build.json`;
  a top-level call must not reach a `let` from a later part. A tab draws
  itself with `onTab(name, fn)` in its own part.
