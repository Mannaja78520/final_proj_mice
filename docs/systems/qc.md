# qc

The QC suite, the gate (`promote.py`) and the tools that keep checks honest.

## Rules and traps

- Every fix needs a check, and it only counts after `tools/sabotage.py` broke
  the fix and watched the check fail.
- `t.ok(cond, label, detail)` takes a detail; `t.eq` and `t.contains` do not.
- One QC-driven process at a time: they share the fake serial port.
- Run `promote.py` by absolute path. Never `--init` a staging that holds work.
- A gate that goes red on browser checks while the PC is busy: run
  `qc/run_qc.py --browsers 3` in the staging, then `promote.py` reuses the
  green receipt (worked 2026-09-21).
