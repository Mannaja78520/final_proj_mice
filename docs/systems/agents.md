# agents

The plan, handoffs, the multi-AI review panel and the files every AI reads first.

## Rules and traps

- Every request goes into `docs/PLAN.html` via `tools/plan.py` the moment it is
  asked; mark `doing` when picked up, `done` when landed.
- To find where a change belongs: `python tools/systems.py which <path>`, then
  read that ONE header in `docs/systems/`. The map is `docs/systems.json`;
  after editing it run `python tools/systems.py build`.
- Every model prompt starts with `tools/ai_brief.txt` and has a line budget.
- `ai_panel.py` judges a model's findings one at a time: only an answer that
  is ALL outage (quota, login, agy's auto-denied tool) counts as FAILED, so a
  review quoting those words is still a review (check_panel).
