# shared-web

One stylesheet and theme set for every page (mice.css, themes).

## Rules and traps

- Read `docs/web_style.md` before building or changing any page: a page is
  assembled from `mice-ui.js` parts (`Mice.Api`, `Mice.Status`, `Mice.TopBar`,
  `Mice.Partner`), not written from scratch (A41-2, 2026-10-14).
- `mice.css` and `mice.js` are compiled into the board's flash; `mice-ui.js`
  is NOT (mice_nong is near its OTA slot). Keep board-site needs in mice.js.
- The browser never probes 127.0.0.1 itself (on a phone that is the phone);
  ask the hub (`/api/partners/health`, `/api/faces/state`).
