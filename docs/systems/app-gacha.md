# app-gacha

Prize machines (gachapon): several gacha boards, kinds, hand-over when one is empty, rules per event and person (local or Google Sheet), webhooks, the prize log; and which Voice answers give a prize plus the Voice question log (A47-2, A47-3).

## Rules and traps

- The page is in tabs (A47-14): every card carries `data-tab`, the row is drawn from `TABS`;
  a new card without a tab is caught by check_gacha_sheet.
- Sheet writes go through `gacha_sheet.py` ways (link / script / service); a write that
  runs beside a prize or a save is in a background thread (`_sheet_soon`), failures logged.
- The sheet's script refuses calls without the hub's secret (.local/gacha/sheet_secret.txt);
  `/api/gacha/sheet/script` hands the secret out, so it is login-only.
- `save_cfg` merges `rules` (the page never gets `sheet_write_url` back, so it sends parts).
