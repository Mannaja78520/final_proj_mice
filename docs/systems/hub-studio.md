# hub-studio

The hub's routes for Nong Studio's files, shared settings and the list of other hubs.

## Rules and traps

- Files are written with write_atomic; names go through safe_name.
- A46-1 talk gestures: gestures.py never decides a pose. Studio fits
  config/gestures.json to the rig and POSTs /api/gestures/fit; the planner only
  strings Studio's checked legs (rest -> gesture -> rest, `direct` pairs) and
  times them (check_gesture_legs). This PC's own gestures and the fit live in
  STUDIO/gestures.json (git-ignored; MICE_GESTURES_MINE in QC). /api/gestures/play
  is gated and never takes over a running show.

- A45-27: when Voice selects a character, Studio's editable gesture library and fit
  use its private `gestures.json`. The shipped library remains shared. Studio saves
  carry the character and gesture-content revision; default is read-only. The hub
  captures the file path once so selection during a save cannot change its target.
