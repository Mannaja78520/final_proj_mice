# hub

The hub program: one HTTP server (port 8642, plus 80 for the short name) that
reaches every board by USB, RS485 or WiFi, flashes them and plays shows.
`main_python/main.py` was split into `hub_*.py` files (A26-76, A26-93), each
its own system with its own header: hub-usb, hub-flash, hub-show, hub-apps,
hub-support (+ hub_update.py), hub-studio, hub-modules, hub-media (+ hub_cam.py). Change one of those and read only its header.

## Interface

- `/api/dev/<cmd|status|files|upload|download|delete>?dev=...` - the ONE way a
  page talks to a board. `dev` is `wifi:<ip>`, `usb:<COM>[:<bus id>]`,
  `hub:<ip>/<dev>` (a board on another PC) or `auto:<board key>` (fastest route).
- `dev_cmd(dev, line)` - the one way hub code sends a command.
- `modules_here()` - the one merged list: a board once, with every route to it.
- `hub_usb.py` - the USB serial manager (port table, per-port lock, reply
  reader), moved out of `main.py` 2026-09-21. main.py imports its names back.
- `hub_show.py` - the show player (ShowPlayer, runs sequences at real times on
  background threads), moved out of `main.py` 2026-09-22. main.py imports its names back.
- `hub_flash.py`, `hub_probe.py` and the `hub_api_*.py` route groups moved
  out 2026-09-22 (A26-93). Handler inherits the route groups (`AppRoutes`,
  `FlashRoutes`...); `api()` asks each in its old place in the chain.
- Checks that read the hub's source use `F.hub_src()` (main.py + every
  `hub_*.py`, with the `_hub.` prefix dropped), so code can move between
  these files without breaking them.

## Moving code out of main.py (the one trap)

- A moved file reads main.py's names LATE, as `_hub.<name>`, after
  `bind(sys.modules[__name__])`. Never `import main` or `from main import`:
  the exe runs main as `__main__`, so that loads a second copy. hub_show.py
  did, and every first show played on a player Studio could not see or stop
  (2026-09-28; check_one_hub holds it). Never copy a value at import:
  QC swaps `main.dev_cmd`, `main.FIRMWARE_DIR`, `main.scan_modules`... and a
  copy would keep the real one.
- Stdlib modules are imported directly; everything main.py defines is `_hub.`.
- A new system needs `names`/`checks` in docs/systems.json, or its scoped gate
  finds no check and runs the full suite.

## Rules and traps

- The hub is the ONE owner of every COM port (per-port lock, released after
  10 s idle). Nothing else may open a port while it runs.
- After changing any `main_python/*.py`, rebuild with
  `python -m PyInstaller --clean MiceHub.spec` - the spec, never a bare
  `--onefile` (that ships an exe with no pages and rewrites the spec).
- `main.py` is in `qc/data/scope.json` fullWhen: any edit runs the full gate.
- Checks assert on what reached the module (`fake_serial.wire`), never on what
  the page says about itself.
- Outside programs (partners.json) are never changed: no git, no files in their
  folder. partner_version.py READS .git (HEAD, branch file, packed-refs) and
  only reports.
