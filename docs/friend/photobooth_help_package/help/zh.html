打开 Photobooth

打开拍照界面

在工具中打开 Photobooth，选择打开拍照亭，在新标签页打开访客拍照界面。

管理拍照亭

选择打开管理页面，使用 Photobooth 账号登录。如果拍照亭无法打开，请再次检查状态。

访客与主办方操作指南

1. 开始拍照

从 Hub 的 Photobooth 页面选 Open booth screen。在访客画面点 Start。没有此按钮时，确认主办方已在 Event Profiles 启用活动。

2. 选择相框

点击尺寸筛选，滑动浏览相框。选 Use this frame，再点 Start with this frame 确认并开始。

3. 看向摄像头

站在预览画面内，倒计时开始时看向摄像头。拍摄张数由所选相框决定。要重来，点 Stop and start over。

4. 检查照片

点击缩略图查看各张照片。需要时用可用的重拍按钮。满意后点 These are good。绿色图案来自模拟摄像头。

5. 给照片加装饰

在 Stickers 中点选贴纸并拖动位置。在 Filters 试用滤镜。完成后点 Finish，再点 Make my photos 确认。

6. 下载成品

将手机连到与拍照亭相同的 Wi-Fi，扫描现场屏幕上的二维码，打开链接，在过期前保存照片。确认能打开链接后点 Done。

7. 登录管理页

在拍照亭电脑上从 Hub 打开 Photobooth，选择 Open admin。在已配对的浏览器输入管理账号，点击 Sign in。

8. 选择当前活动

在 Event Profiles 新建或编辑活动。为访客应看到的活动点 Activate，确认显示 Active。可用 Duplicate 复用旧设置。 示例按钮为 Activate Demo Event。

9. 设置活动外观和相机

打开 New profile 或 Edit。设置启动页、主题、图片、尺寸和倒计时。用现场屏幕尺寸查看预览，设置保留规则，再点 Save profile。 向下滚动可查看其余设置和保存按钮。

10. 添加和预览相框

在 Frames 先确认尺寸与布局。点 Add frame，上传为该布局设计好的 PNG。查看预览并确认活动开放此尺寸。

11. 开放前试拍

在 Test booth 选择活动和摄像头，点 Start booth test，走一遍拍摄和查看流程。如果使用电视，确认电视在同一 Wi-Fi，摄像头由拍照亭电脑提供。

12. 查找拍照记录

打开 History，选择日期和活动。用 Photos made、Ended early 或 In progress 筛选，再打开需要的记录。

13. 查看活动统计

打开 Statistics，选活动和日期。对比访问、成品照片和下载次数，根据高峰时段安排人员。 在 Visits by hour 可查看高峰时段。

14. 查看近期操作

打开 Activity log，选择 Booth、Guest phones、Organizers 或 System 查看发生了什么及时间。

15. 设置照片保留时间

打开 Retention，核对照片、链接与记录的保留期限。在开放前于活动资料中选好策略。清理前确认将移除的内容。 向下滚动到 Clean up now 可见清理选项。

16. 检查拍照亭状态

打开 System，在 Health 核对数据库、剩余空间和当前活动。如果来宾无法打开链接，检查现场 System 页面上的发送地址。

拍照亭无法打开时

回到 Hub 点击 Check again。若显示未配对，在拍照亭电脑启动 Photobooth，使用它打开的已配对标签页。没有摄像头画面时，允许访问并关闭占用摄像头的应用。 配对后，如果该页仍开着，请点 Try again。
