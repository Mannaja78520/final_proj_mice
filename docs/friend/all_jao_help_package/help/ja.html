🎮 All-Jao Games — ミニゲームと景品の自動プレゼント

MICE からイベントのゲームを遊べます。遊べるゲームは、インストールした版とイベント設定によって変わります。

MICE からゲームを開く

ツールで All-Jao Games を開き、新しいタブで開くボタンを選びます。

ゲームを選ぶ

最初の画面からゲーム一覧に進み、遊べるルーレット、絵合わせ、クレーンゲーム、クイズを選びます。ゲーム一覧は All-Jao 独自のタイ語表示と配色です。

このPCではハブへのログインは不要新

ゲームには独自のログインがあるので、MICE を動かしている PC で開いても何も聞かれません。ネットワーク上の別の端末から開くときは、会場の WiFi にいる誰もこの PC でプログラムを始められないよう、ハブが先にログインを求めます。

勝てば本物の景品新

ハブの中で遊ぶと、ルーレット、クレーン、クイズ、神経衰弱での勝ちで景品マシンが景品を出し、プレイヤーにどこで受け取るかを知らせます。どの結果で何がもらえるかは、次で設定します： 景品マシン ▸ 景品を渡すゲーム。クイズでは次を入力します： スコア（下限） 得点がこの値以上のときだけ景品を渡します（終わったクイズの各ラウンドは勝ちの結果として数えます。数字か 80% のようなパーセントで書きます。ゲームは自分の最高点を知っているので、問題を増やしても直す必要はありません。「もう一度」と書かれたルーレットの区画は景品を出しません）。ルーレットやクレーンのゲームで入力したプレイヤー名は、1 人あたりの上限に使われます。ゲームはデータを自分の小さなサーバー（ハブが「開く」ボタンで起動する Node）に保存します。勝ちが景品マシンに届くよう、ハブ経由で遊んでください。

ゲームを開くボタンは、準備の確認より先にタブを開くので、ネットワークを待った後でブラウザーにブロックされることがありません。タブが開けないときは、ポップアップを許可してからもう一度押してください。

ゲームの遊び方と設定

1. プレイヤー画面を開く

Hub のツールで All-Jao Games を新しいタブに開きます。開始画面で เลือกเกมแล้วเริ่มสนุก を押すとゲストで遊べます。ゲームを編集するときは主催者アカウントを使います。

2. ルーレットを回す

วงล้อสุ่ม を選びます。主催者の案内に従い、必要なら下の欄に名前を入れます。ルーレットを一度押して結果を待ち、画面の指示に従って景品を受け取ります。

3. 絵合わせをする

จับคู่รูปภาพ を選び、เริ่มเกม を押します。カードを二枚ずつめくり、時間内にすべてのペアをそろえます。เริ่มใหม่ で次のラウンドを始めます。 写真はラウンド開始後の画面です。

4. カプセルクレーンで遊ぶ

ตู้คีบลูกบอล を選びます。必要なら操作ボタンの上の欄に名前を入れます。左右の矢印で位置を合わせ、คีบ を押します。カプセルが開いて結果が出るまで待ちます。

5. クイズに答える

รู้ใจแค่ไหน を選びます。一覧になければ別のゲームを開き、上端の四番目のタブを使います。名前を入力して เริ่มเกม を押し、全問回答後に得点・時間・順位を確認します。

6. ルーレットの景品を設定する

主催者でログインし、ตั้งค่าเกม の 01 を開きます。景品名と数量を入力し、在庫と確率を確認して保存します。プレイヤー画面を開く前にプレビューを確認します。 保存ボタンは景品一覧の下にあります。

7. カードと制限時間を設定する

設定で 02 を選び、制限時間とカード枠数を指定します。ペア名と二枚の画像を選んで保存し、一度試します。 カードのペア一覧の下までスクロールして保存します。

8. クレーンの景品を設定する

設定で 03 を選び、景品・数量・抽選の重みを入力します。在庫と表示された確率を確認して保存します。この設定はクレーンに適用されます。 保存ボタンはカプセル一覧の下にあります。

9. クイズの問題を編集する

設定で 04 を選び、質問と選択肢を追加します。各問の正解を選び、บันทึกคำถาม を押します。下部にプレイヤーの順位と履歴があります。 保存ボタンは質問一覧の下にあります。

ゲームを開けない、または保存できないとき

Hub のポップアップを許可し、All-Jao のタイルから再度開きます。別の画面で設定が更新された場合は再読み込みし、最新値を確かめて編集します。

Hub で景品ルールを準備する

景品機のページで景品付きゲームの設定を開きます。ゲーム、結果、在庫のある景品機を選んで保存します。当日は Hub のゲームリンクを使い、開場前にルールに合う結果を一度試します。
