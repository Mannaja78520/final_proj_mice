🎮 All-Jao Games — mini-games and automatic prize giving

Play event games through MICE. The games available may change with the installed version and event settings.

Open the games from MICE

In Tools, open All-Jao Games and choose Open in a new tab.

Choose a game

On the first screen, continue to the game list. Choose the wheel, picture matching claw game or quiz as available. The game lobby uses All-Jao’s own Thai interface and colors.

No hub sign-in needed on this PCnew

The games have their own login, so opening them on the PC that runs MICE asks for nothing. Opened from another device on the network, the hub asks you to sign in first, so nobody on the venue WiFi can start programs on this PC.

A win gives a real prizenew

Played inside the hub, a win in the wheel, claw, quiz or memory game can make a prize machine give a prize and tells the player where to collect it. Which result gives what is set on Prize machines ▸ Games that give a prize. For the quiz, fill Score from to give a prize only from that score up (every finished quiz round counts as a win result; write a number or a percent such as 80%; the game says its top score, so more questions need no change; a wheel slice that says “try again” never gives a prize). The player's name typed in the wheel or claw game is used for the per-person limit. The games now keep their data in their own small server (Node, started by the hub with the Open button); play them from the hub so a win reaches the prize machines.

The open-game button opens the tab first, before checking readiness, so the browser does not block it after waiting for the network. If the tab cannot open, allow pop-ups and press it again.

Play and set up the games

1. Open the player screen

In Hub Tools, open All-Jao Games and choose Open in a new tab. On the welcome screen, choose เลือกเกมแล้วเริ่มสนุก to play as a guest. Enter the event’s organizer account here only when you need to edit games.

2. Spin the wheel

Choose วงล้อสุ่ม. Enter the player’s name beneath the wheel if the organizer asks. Tap the wheel once and wait for the result. Collect a prize only if the screen directs you to do so.

3. Match pictures

Choose จับคู่รูปภาพ and press เริ่มเกม. Turn over two cards at a time. Match every pair before the timer runs out. Use เริ่มใหม่ to start a new round. The picture shows a round already started.

4. Use the capsule claw

Choose ตู้คีบลูกบอล. If requested, enter the player’s name in the box above the controls. Use the left and right arrows to line up the claw, then press คีบ. Wait for the capsule to open and read the result.

5. Take the quiz

Choose รู้ใจแค่ไหน. If the tile is absent, open another game and use the fourth tab at the top. Enter a name, press เริ่มเกม and answer the questions. Check the score, time and ranking at the end.

6. Set wheel prizes

Sign in as the organizer and open ตั้งค่าเกม, then 01. Add prize names and quantities, check remaining stock and odds, and save. Use the wheel preview before opening the player screen. Scroll below the prize list for the save button.

7. Set cards and time

In settings choose 02. Set the time and number of card slots. Name the pairs and choose the two images for each pair. Save and try one round. Scroll past the card pairs to save.

8. Set capsule prizes

In settings choose 03. Add items, quantities and draw weights. Check the remaining stock and displayed odds, then save. These settings apply to the claw game. Scroll below the capsule list for the save button.

9. Edit questions

In settings choose 04. Add questions and choices, mark the correct choice for each, and press บันทึกคำถาม. Check player results in the ranking and history farther down. The save button is below the question list.

If a game does not open or save

Allow pop-ups for Hub, then use the All-Jao tile to open the game again. If the settings changed on another screen, reload the game, check the latest values and reapply your edit.

Prepare a prize rule in Hub

Open Prize machines and find Games that give a prize. Choose the game and result, select the stocked prize machine, and save the rule. Use the Hub’s game link for the event. Test one configured win before guests play.
