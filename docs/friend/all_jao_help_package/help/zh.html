🎮 All-Jao Games——迷你游戏与自动发放奖品

通过 MICE 玩活动游戏。游戏会随安装版本和活动设置而变化。

从 MICE 打开游戏

在工具中打开 All-Jao Games，再选择在新标签页中打开。

选择游戏

在首页进入游戏列表，按现场开放情况选择转盘、图片配对、抓娃娃或问答。游戏大厅使用 All-Jao 自己的泰语界面和配色。

在这台电脑上无需登录中心新

游戏有自己的登录，所以在运行 MICE 的电脑上打开不会要求任何东西。从网络中的其他设备打开时，中心会先要求登录，这样场地 WiFi 上的任何人都无法在这台电脑上启动程序。

获胜就能得到真实奖品新

在中心内游玩时，转盘、抓娃娃机、问答或配对游戏中的获胜可以让奖品机发放奖品，并告诉玩家去哪里领取。哪种结果得到什么，设置在 奖品机 ▸ 发放奖品的游戏。对于问答游戏，请填写 得分从 这样只有得分达到该值及以上才发放奖品（每一轮结束的问答都算作获胜结果；可填数字或百分比，例如 80%；游戏会说明自己的最高分，所以增加题目无需修改；写着“再试一次”的转盘格永远不发奖品）。在转盘或抓娃娃机游戏中输入的玩家名字用于每人限额。游戏现在把数据保存在它自己的小型服务器里（由中心用“打开”按钮启动的 Node）；请通过中心来玩，这样获胜结果才能传到奖品机。

“打开游戏”按钮会先打开标签页，再检查是否就绪，这样浏览器就不会在等待网络后将其拦截。如果标签页无法打开，请允许弹出窗口后再按一次。

游玩与设置游戏

1. 打开玩家界面

在 Hub 的工具页打开 All-Jao Games，在新标签页中打开。欢迎页选 เลือกเกมแล้วเริ่มสนุก 以访客身份游玩。编辑游戏时才需要主办方账号。

2. 转动转盘

选择 วงล้อสุ่ม。主办方需要时，在转盘下方输入玩家姓名。点击转盘一次并等待结果，按画面提示领奖。

3. 配对图片

选择 จับคู่รูปภาพ，点击 เริ่มเกม。每次翻两张牌，在倒计时结束前配完。点 เริ่มใหม่ 可开新一局。 图中是一局已经开始的游戏。

4. 玩抓球机

选择 ตู้คีบลูกบอล。需要时在控制键上方的框内输入姓名。用左右箭头对准抓爪，再按 คีบ。等待胶囊打开并查看结果。

5. 参加问答

选择 รู้ใจแค่ไหน。如大厅没有该卡片，打开另一款游戏并点顶部第四个标签。输入姓名，点 เริ่มเกม，答完后查看成绩、用时和排名。

6. 设置转盘奖品

用主办方账号登录，打开 ตั้งค่าเกม 后选 01。添加奖品名称和数量，检查库存与概率后保存。打开玩家页前先看转盘预览。 向下滚动到奖品列表下方找保存按钮。

7. 设置卡片和时间

设置中选 02。设定计时和卡片格数。为每对卡命名并选择两张图片。保存并试一局。 向下滚过卡片配对列表后保存。

8. 设置胶囊奖品

设置中选 03。添加奖品、数量和抽取权重。核对余量与显示概率后保存。这些设置用于抓球机。 向下滚动到胶囊列表下方找保存按钮。

9. 编辑问答题

设置中选 04。添加题目及选项，标记每题的正确答案，然后点 บันทึกคำถาม。往下查看排名和玩家历史。 保存按钮在题目列表下方。

游戏无法打开或保存时

允许 Hub 打开弹窗，然后从 All-Jao 页面重试。如果其他屏幕已改动设置，重新加载，核对最新值后再编辑。

在 Hub 设置领奖规则

打开礼品机页面，找到可发奖的游戏。选择游戏、结果和有库存的礼品机并保存。活动中使用 Hub 的游戏链接，开放前试一次符合规则的结果。
