# ติดตั้งบนเครื่องลูกค้า (เครื่องไหนก็ได้ มีแอปไม่ครบก็ได้)

ขอเมื่อ 2026-10-27 (A51-2): ระบบจะถูกเอาไปลงหลายเครื่อง แต่ละเครื่องอาจไม่มี
face reg, photobooth หรือตู้รางวัล หรืออาจมีแอปมากกว่าของเรา ทุกอย่างขาดได้
และเพิ่มได้ตลอดเวลา โดยไม่ต้องแก้โค้ด รายละเอียดรูปแบบไฟล์อยู่ที่
[docs/extensions.md](extensions.md) ส่วนแผนผังโฟลเดอร์อยู่ที่ [docs/LAYOUT.md](LAYOUT.md)

## 1. ตัวกลาง (hub) ต้องมีทุกเครื่อง

hub คือศูนย์กลาง แอปอื่นทั้งหมดเป็นส่วนเสริมของมัน

| วิธี | ต้องมีอะไร | เปิดยังไง |
|---|---|---|
| `MiceHub.exe` (แนะนำสำหรับลูกค้า) | Windows อย่างเดียว ไม่ต้องลง Python | ดับเบิลคลิก `dist/MiceHub.exe` |
| จากซอร์ส | Python 3.8+ แล้ว `pip install -r requirements.txt` | `python main_python/main.py` หรือ `main_python/run_hub.bat` |

เปิดแล้วไปที่ `http://127.0.0.1:8642/` จะมีลิงก์ WiFi ให้มือถือในวงเดียวกันเปิดได้ด้วย
แนะนำให้วางโฟลเดอร์ของเรา (`mice_system`, ชื่อเดิม `code`) ไว้ข้าง ๆ โฟลเดอร์แอปอื่น
เช่น

```
D:\mice\
  mice_system\        hub + แอปของเรา
  Face_Regonize\      (ถ้ามี) แอปจดจำหน้า
  All-Jao-Games\      (ถ้ามี) เกมแจกรางวัล
  photobooth\         (ถ้ามี) ตู้ถ่ายรูป
```

hub จะเจอแอปที่อยู่ข้าง ๆ เองโดยไม่ต้องตั้งค่า ถ้าเก็บไว้ที่อื่นก็เลือกโฟลเดอร์เองได้ (ข้อ 3)

## 2. แต่ละชิ้นต้องมีอะไร

| ชิ้น | ต้องลงเพิ่ม | ไม่มีแล้วเป็นยังไง |
|---|---|---|
| Nong Studio, กล้อง ESP32, รีโมททีวี, ตู้รางวัล (gacha) | ไม่ต้อง อยู่ใน hub แล้ว | ถอดได้ใน "แอปในเครื่องนี้" ถ้าไม่ใช้ |
| เสียง (Voice) | ไม่ต้อง; ถ้าจะใช้แบบออฟไลน์ ลงโมเดลใน `.local/` | ใช้แบบออนไลน์ได้ หรือถอดออก |
| Reconize (จดจำหน้า) | โฟลเดอร์ `Face_Regonize` ของเพื่อน + สิ่งที่ README ของเขาบอก | ไทล์ Reconize ซ่อนเอง |
| Photobooth | โฟลเดอร์ photobooth ของเพื่อน | ไทล์ Photobooth ซ่อนเอง |
| All-Jao Games | โฟลเดอร์ `All-Jao-Games` ของเพื่อน | ไทล์ All-Jao ซ่อนเอง |
| บอร์ดโมดูล (nong, lift, cam, gacha) | สาย USB/RS485 หรือ WiFi เดียวกัน | หน้าโมดูลว่างเฉย ๆ |

แอปของเพื่อน เราไม่แก้ไฟล์ในโฟลเดอร์เขาเลย hub แค่อ่านและเปิดโปรแกรมของเขา

## 3. เพิ่ม / ถอด / อัปเดตแอป (ไม่ต้องแก้โค้ด)

หน้า hub > แท็บ **เครื่องมือ** > การ์ด **แอปในเครื่องนี้**

- **เพิ่มแอป**: กด "เลือกโฟลเดอร์…" (เปิดบนเครื่องนั้นเอง) หรือพิมพ์ที่อยู่โฟลเดอร์ แล้วกด "เพิ่มแอป"
  hub ดูไฟล์ `mice-app.json` ของแอปก่อน ถ้าไม่มีก็ใช้แม่แบบใน `config/partners.json`
- **เจอในเครื่องนี้ ยังไม่ได้เพิ่ม**: แอปที่ hub เจอข้าง ๆ แล้ว กดเพิ่มได้เลย
- **ถอด**: แค่เอาออกจากรายการของเครื่องนี้ ไม่ลบไฟล์อะไร กด "ใส่กลับ" เพื่อเอากลับ
- **อัปเดต**: ใช้คำสั่ง `update` ของแอปเอง ถ้าไม่มีและเป็นโฟลเดอร์ git ใช้ `git pull --ff-only`

รายการของแต่ละเครื่องเก็บใน `main_python/extensions.json` เครื่องเดียว ไม่ขึ้น git
ก๊อปไปเครื่องอื่นไม่ได้ (แต่ละเครื่องตั้งเอง)

## 4. ตัวติดตั้งของแอป (setup) เพิ่มตัวเองเข้า hub

หลังก๊อปไฟล์เสร็จ ตัวติดตั้งเรียกอย่างใดอย่างหนึ่ง (บนเครื่องเดียวกับ hub ไม่ต้องล็อกอิน)

```
python tools/add_app.py "D:\mice\LuckyDraw" --wait
```

หรือเครื่องที่ไม่มี Python (PowerShell):

```
Invoke-RestMethod -Method Post http://127.0.0.1:8642/api/extensions/add `
  -ContentType application/json -Body '{"folder":"D:\\mice\\LuckyDraw"}'
```

ถ้า hub ยังไม่เปิด `--wait` จะรอจนเปิด ถ้าใช้ PowerShell ให้เปิด hub ก่อน

## 5. ย้ายหรือเปลี่ยนชื่อโฟลเดอร์

- ย้ายทั้งชุด (hub + แอปข้าง ๆ) ไปที่อื่น: ใช้ได้เลย เพราะที่อยู่ใน `config/partners.json`
  เขียนเป็น `{parent}/...` (โฟลเดอร์ที่ hub อยู่ข้างใน)
- ย้ายแอปเดียวไปที่อื่น: เพิ่มโฟลเดอร์ใหม่อีกครั้งในข้อ 3 ที่อยู่ที่เลือกเองชนะเสมอ
- Photobooth ตั้งที่อยู่ไว้ที่ `C:/Photobooth/Main/app` ถ้าอยู่ที่อื่นให้เพิ่มโฟลเดอร์เองในข้อ 3

## 6. เช็คว่าใช้ได้

1. เปิด hub แล้วดูรายการแอปในแท็บ **เครื่องมือ**: เห็นเฉพาะแอปที่เครื่องนี้มี
2. แท็บ **เครื่องมือ** > **แอปในเครื่องนี้**: แอปของเพื่อนขึ้นว่า "แสดงอยู่"
3. นักพัฒนา: `python qc/run_qc.py --quiet check_extensions`
