Photobooth を開く

撮影画面を開く

ツールで Photobooth を開き、撮影画面を開くボタンを押すと、新しいタブに来場者用の撮影画面が表示されます。

フォトブースを管理する

管理画面を開き、Photobooth のアカウントでログインします。開けない場合は、もう一度状態を確認してください。

来場者と主催者の操作手順

1. 撮影を始める

Hub の Photobooth で Open booth screen を選びます。来場者用画面の Start を押します。表示されない場合は Event Profiles でイベントが有効か確認します。

2. フレームを選ぶ

サイズで絞り込み、スワイプやスクロールでフレームを見ます。Use this frame で選び、Start with this frame で確定します。

3. カメラを見る

プレビューの範囲に立ち、カウントダウンが始まったらカメラを見ます。選んだフレームに必要な枚数を撮影します。やり直すには Stop and start over を押します。

4. 撮影した写真を確認する

サムネイルを選んで各写真を確認します。必要なら表示された撮り直しボタンを使います。確認後、These are good を押します。緑の画像は模擬カメラの映像です。

5. 写真を飾る

Stickers でステッカーを押して追加し、ドラッグして移動します。Filters で効果を試します。Finish を押し、Make my photos で確定します。

6. 写真を持ち帰る

スマートフォンをブースと同じ Wi-Fi に接続します。実際の画面の QR コードからリンクを開き、期限内に写真を保存します。リンクが開くことを確かめて Done を押します。

7. 主催者としてログインする

ブース用 PC で Hub の Photobooth を開き、Open admin を選びます。ペアリング済みブラウザーで主催者アカウントを入力し、Sign in を押します。

8. 公開するイベントを選ぶ

Event Profiles でイベントを作成または編集します。公開するものを Activate で有効にし、Active の表示を確認します。既存の設定は Duplicate で複製できます。

9. 見た目と撮影方法を設定する

New profile または Edit を開きます。開始画面、テーマ、画像、サイズ、カウントダウンを設定します。画面サイズを合わせてプレビューし、保存期間を選んで Save profile を押します。

10. フレームを追加・確認する

Frames でサイズとレイアウトを確認します。Add frame で、そのレイアウト用に作成した PNG を登録します。プレビューとイベントで使えるサイズを確認します。

11. 開場前に試す

Test booth でイベントとカメラを選び、Start booth test を押して撮影から確認まで試します。テレビを使う場合は同じ Wi-Fi に接続し、カメラはブース用 PC のものを使います。

12. 過去の利用を探す

History で期間とイベントを選びます。Photos made、Ended early、In progress で絞り込み、対象の記録を開きます。

13. イベントの集計を見る

Statistics でイベントと期間を選びます。利用数、完成写真数、ダウンロード数を確認します。混雑時間を見てスタッフ配置に役立てます。

14. 操作履歴を確認する

Activity log で Booth、Guest phones、Organizers、System を選び、何がいつ起きたか確認します。

15. 写真の保存期間を決める

Retention で写真、リンク、利用記録の保存期間を確認します。公開前にイベントのプロフィールでポリシーを選びます。クリーンアップ前に削除対象を確認します。

16. ブースの状態を確認する

System の Health でデータベース、空き容量、公開中のイベントを確認します。来場者がリンクを開けなければ、実際の System にある配信先を確認します。

ブースを開けないとき

Hub に戻って Check again を押します。未ペアリングの場合はブース用 PC で Photobooth を起動し、自動で開くタブを使います。映像が出ない場合はカメラを許可し、使用中の別アプリを閉じます。
