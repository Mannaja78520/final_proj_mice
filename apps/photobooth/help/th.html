เปิด Photobooth

เปิดหน้าตู้

ใน Tools เปิด Photobooth แล้วกด Open booth screen เพื่อเปิดหน้าถ่ายภาพในแท็บใหม่

จัดการตู้

กด Open admin แล้วเข้าสู่ระบบด้วยบัญชีของ Photobooth หากเปิดไม่ได้ ให้กด Check again เพื่อตรวจสถานะ

วิธีใช้สำหรับผู้ร่วมงานและผู้จัดงาน

1. เริ่มถ่ายภาพ

จากหน้า Photobooth ของ Hub กด Open booth screen ที่จอผู้ร่วมงานแตะ Start ถ้าไม่เห็นปุ่มนี้ ให้ผู้จัดงานตรวจว่าเปิดใช้งานโปรไฟล์ใน Event Profiles แล้ว

2. เลือกกรอบ

แตะขนาดเพื่อกรอง ปัดหรือเลื่อนดูกรอบ กด Use this frame แล้วกด Start with this frame เพื่อยืนยันและเริ่ม

3. มองกล้อง

ยืนให้อยู่ในภาพตัวอย่างแล้วมองกล้องเมื่อนับถอยหลัง ตู้จะถ่ายตามจำนวนที่กรอบกำหนด กด Stop and start over หากต้องเริ่มใหม่

4. ตรวจรูปที่ถ่าย

แตะภาพย่อเพื่อดูแต่ละรูป ใช้ปุ่มถ่ายใหม่ที่แสดงถ้าต้องการ เมื่อพอใจแล้วกด These are good ภาพสีเขียวมาจากกล้องจำลอง

5. แต่งรูป

ใน Stickers แตะสติกเกอร์แล้วลากไปวาง ลองเอฟเฟกต์ใน Filters เมื่อเสร็จกด Finish แล้วกด Make my photos เพื่อยืนยัน

6. รับรูปเข้ามือถือ

ให้มือถืออยู่บน Wi-Fi เดียวกับตู้ สแกน QR บนจอจริง เปิดลิงก์แล้วบันทึกภาพก่อนหมดอายุ เมื่อเช็กว่าเปิดลิงก์ได้แล้วกด Done

7. เข้าระบบผู้จัดงาน

บนเครื่องตู้ เปิด Photobooth ใน Hub แล้วกด Open admin ในเบราว์เซอร์ที่จับคู่แล้ว ใส่บัญชีผู้จัดงานของ Photobooth แล้วกด Sign in

8. เลือกงานที่จะเปิด

ใน Event Profiles สร้างหรือแก้โปรไฟล์งาน กด Activate ที่งานที่ต้องการเปิดให้ผู้ร่วมงาน แล้วเช็กว่าขึ้น Active ใช้ Duplicate ถ้าต้องการเริ่มจากรูปแบบเดิม ในภาพตัวอย่าง ปุ่มชื่อ Activate Demo Event

9. ตั้งหน้าตาและการถ่าย

เปิด New profile หรือ Edit ตั้งหน้าเริ่ม ชุดสี รูป ขนาด และเวลานับถอยหลัง ตรวจตัวอย่างตามขนาดจอ เลือกการเก็บข้อมูล แล้วกด Save profile เลื่อนลงเพื่อดูค่าที่เหลือและปุ่มบันทึก

10. เพิ่มและลองดูกรอบ

ใน Frames เช็กขนาดและแบบจัดวางก่อน กด Add frame แล้วอัปโหลด PNG ที่ทำไว้สำหรับแบบนั้น ดูตัวอย่างกรอบและตรวจว่างานเปิดให้เลือกขนาดนี้

11. ลองตู้ก่อนเปิดงาน

ใน Test booth เลือกงานและกล้อง แล้วกด Start booth test ลองถ่ายและตรวจรูป หากใช้ทีวี ให้เช็กว่าอยู่บน Wi-Fi เดียวกัน โดยใช้กล้องจากเครื่องตู้

12. ค้นรอบถ่ายที่ผ่านมา

เปิด History เลือกช่วงวันและงาน ใช้ Photos made, Ended early หรือ In progress เพื่อกรองก่อนเปิดดูรอบที่ต้องการ

13. ดูยอดรวมงาน

เปิด Statistics เลือกงานและช่วงวัน เปรียบเทียบจำนวนรอบ รูปที่ทำเสร็จ และการดาวน์โหลด ดูช่วงที่คนใช้เยอะเพื่อจัดคนดูแล ดูช่วงที่คนใช้มากในหัวข้อ Visits by hour

14. ดูเหตุการณ์ล่าสุด

เปิด Activity log เลือก Booth, Guest phones, Organizers หรือ System เพื่อดูว่าเกิดอะไรขึ้นและเมื่อไร

15. ตั้งระยะเวลาเก็บภาพ

เปิด Retention ดูนโยบายของรูป ลิงก์ และประวัติ เลือกนโยบายในโปรไฟล์ก่อนเปิดให้ใช้งาน ตรวจรายการที่จะลบก่อนสั่งล้าง เลื่อนลงไปที่ Clean up now เพื่อดูตัวเลือกการล้าง

16. ตรวจสถานะตู้

เปิด System ดูฐานข้อมูล พื้นที่ว่าง และงานที่เปิดอยู่ใน Health หากผู้ร่วมงานเปิดลิงก์ไม่ได้ ให้ตรวจที่อยู่รับภาพในหน้า System ของเครื่องจริง

เมื่อตู้เปิดไม่ได้

กลับไปที่ Hub แล้วกด Check again หากจอแจ้งว่ายังไม่จับคู่ ให้เปิด Photobooth จากเครื่องตู้และใช้แท็บที่แอปเปิดให้ หากภาพกล้องไม่ขึ้น ให้อนุญาตกล้องและปิดแอปอื่นที่ใช้กล้อง เมื่อจับคู่แล้ว หากหน้านี้ยังเปิดอยู่ให้กด Try again
