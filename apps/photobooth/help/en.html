Open Photobooth

Open the booth

In Tools, open Photobooth and choose Open booth screen ↗ to start the guest screen in a new tab.

Manage the booth

Choose Open admin ↗ and sign in with the Photobooth account. Use Check again if the booth does not open.

Guest and organizer walkthrough

1. Start a guest session

From the Hub’s Photobooth tile, choose Open booth screen. On the guest screen, tap Start. If there is no Start button, check that the host has activated the event in Event Profiles.

2. Choose your frame

Tap a size to narrow the choices. Swipe or scroll through the frames. Press Use this frame, then Start with this frame to confirm the preview and begin.

3. Look at the camera

Stand in the preview area and look at the camera when the countdown starts. The booth takes the number of photos required by the chosen frame. Use Stop and start over to restart.

4. Check the photos

Select a thumbnail to inspect its photo. Use the available retake buttons if needed. When ready, press These are good. The green images are from a synthetic camera.

5. Add stickers or filters

In Stickers, tap a sticker and drag it to move it. In Filters, try an effect. Choose Finish, then confirm with Make my photos.

6. Take the photos home

Connect your phone to the same Wi-Fi as the booth. Scan the QR on the live booth screen, open the link and save the pictures before it expires. Press Done after checking that the link opens.

7. Sign in as the organizer

On the booth computer, open the Hub’s Photobooth page and choose Open admin. In the paired browser, enter the Photobooth organizer account and press Sign in.

8. Pick the live event

In Event Profiles, create or edit an event. Press Activate for the profile guests should see and check that it shows Active. Use Duplicate to start from a previous layout.

9. Set the event look and camera behavior

Open New profile or Edit. Set the Start screen, theme, images, sizes and countdown. Check the preview for your screen size, choose retention, then Save profile.

10. Add and preview frames

In Frames, check the size and layout first. Choose Add frame and upload a finished PNG made for that layout. Check the frame preview and whether the event offers that size.

11. Test the booth before opening

In Test booth, pick the event and camera, then press Start booth test. Walk through capture and review. If you use a TV, check that it is on the same Wi-Fi while the booth PC supplies the camera.

12. Find a past visit

Open History. Choose a date range and event. Use Photos made, Ended early or In progress to narrow the list before opening a visit.

13. Check event totals

Open Statistics and pick the event and date range. Compare visits, finished photos and downloads. Look at busy hours to plan staffing.

14. See recent changes

Open Activity log. Choose Booth, Guest phones, Organizers or System to identify what happened and when.

15. Set how long photos stay

Open Retention. Review the policy for photos, links and visit records. Select the event’s policy in its profile before opening to guests. Check what will be removed before running cleanup.

16. Check the booth’s status

Open System. Check the database, available space and live event under Health. If guests cannot open links, check the delivery address shown on your own System page.

If the booth does not open

Return to Hub and choose Check again. If the screen says it is not paired, start Photobooth from the booth computer and use the paired tab it opens. If the camera is blank, allow access and close other apps using it.
