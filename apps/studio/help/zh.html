打开最新作品，包含动作和音乐

中心主页有应用 最新作品 用于已安装的作品。还没有列表的电脑可以直接导入文件。在 Nong Studio 中按 打开带音乐的作品 然后选择片段或文件 .nong.json 它将动作、骨骼绑定（rig）和音乐保存在单个文件中。系统在切换项目前会先读取并检查文件。如果有未保存的内容，会提示您先保存（Save）或取消，并让您选择是使用该项目的 rig 还是保留当前设置。更换 rig 可能会根据新的机械极限调整动作姿态或时间节奏。

按 带音乐试一试 即可在屏幕上配合原来的音乐查看动作。可以暂停、回到开头或拖动时间条。音乐是预览的时钟，所以标签页变慢时它也不会与动作脱节。如果音乐比动作先结束，剩下的部分是静音；循环时会在动作结束后重新开始音乐。打开作品或使用此预览不会向真实机器人发送任何命令。“在机器人上运行”按钮是单独的步骤。

保存 音乐也会保存在项目里，重新打开时仍然在，或者按 下载动作+音乐 将单个文件移到另一台电脑。草稿的音乐单独保存在浏览器里；如果该存储被关闭或清除，可能需要重新选择原文件，而恢复的动作仍然在。对于真实机器人，请使用 YAML 文件以及与 play: 命令同名的 MP3，放在 SD 卡上，按原有方式上传。系统不会自动上传或让机器人播放。

项目名称可以使用泰文和英文字母、数字、空格以及 _ - . ，但不能使用表情符号、/ \ :，也不能使用 Windows 保留的名称（如 con、nul、com1）。页面会用简单的话提示，已保存的内容不会被覆盖。

无法绘制 3D 的设备（电视、旧电脑，或关闭了显卡的浏览器）： Studio 仍然可以打开并使用。滑块、时间轴和在机器人上播放都正常，只是 3D 机器人画面会显示一条消息，说明这台设备无法绘制。要看到机器人，请用较新的浏览器或另一台电脑打开。

自动分离舞段： 默认的“自动”会自己检测新片段中的多个人物和镜头角度变化。使用“自动”或“群舞”时，系统每次都会比较整个片段中的动作，不会预先固定男/女的位置。手臂相同但腰部扭转或肩膀倾斜不同的人，可能被分进不同的舞段。选择“舞蹈编排”可查看每一段，或选择“分别保存舞段”，把证据持续不同、画面可靠、且达到默认设置所定画面比例的舞段另存为独立项目。“片段（Fragment）”是尚无法确认为新舞段的一段内容，可逐个查看和保存，不会每次镜头切换都算作新的舞段。如果新角度无法与之前的舞段清楚匹配，系统会结合舞者的外观和对所有组同时匹配，并在匹配仍不明确时标记“check cut”。仍不明确的新角度会保持原姿势，不会仅因时间过去就变得可靠。只有当该画面中看到的多个人确实做同一个姿势时，才会使用已确认的共享姿势。“% reliable”报告表示可用画面的比例，并不保证是同一个人。用户也可以选择自己手动指定人物。

无法匹配到同一个人的镜头切换： 系统会自动把它拆成多个场景片段，并选出在该舞段中连续出现的主要舞者，而不是随每个画面的置信度来回切换。每个部分的视频范围和动作时间对齐开始。修改视频范围时，会取消之前的读取并分析新的范围，不会在可见片段之前补上很长的静止站立。“生成并保存”会分别保存达到标准的舞段或片段，不会生成把不同动作猜成同一个人的演出。含糊的跨镜头匹配并不保证性别或同一个人。

连续舞蹈： 默认会保持姿势的形状，并根据机器人的限制增加时间。若想保持原来的音乐节奏，请选择“配合音乐”，这可能会减小运动幅度。系统会按时间过滤抖动，减少短暂的反向和关节角度的突变。当人在换姿势后静止不动时，机器人仍会运动到它在静止之前接受的姿势，不会因滤波而半途停下。开场姿势和静止片段会被保留，也不会把未来的姿势拉进来填补看不见的画面。滤波之后会再次检查碰撞和时间，并显示前后的反向次数。原始画面和误差报告仍用来检查滤波是否吃掉了太多姿势细节。骨架和电机的限位可能使某些姿势仍与真人不同。

跟随单人视频或群舞

比视频播放器最低速度还慢的绕行阶段，会按机器人的时钟一帧一帧地推进画面，同时声音暂停。用“同时播放”来停止或继续。更换视频或模式会立即恢复正常速度，并取消之前的读取。原始音乐不会被发送去绑定已被拉长时间的序列，因为节拍会错位；必须使用调整过时间的音乐文件。对于加油助威序列，会成对提供调整过时间的音乐文件。

在“视频”页面，可以分别把“表演者”选为“单个表演者”或“群舞”，把“镜头”选为“单一镜头”或“切换镜头 / 视角”。读取片段后，会出现可在“跟随”中选择的表演者编号。不同的舞段，例如男舞者和女舞者的，不会被平均在一起。请分别检查并以各自的名称保存每个人或每个舞段。

“转动腰部”使用躯干相对于髋部的角度，“跟随肩部倾斜”使用肩膀相对于躯干的角度，并与骨架中的真实机构对照。静止站立的人不会拉入未来的姿势来填补，也不会跨越镜头切换做平滑。侧面或俯视的摄像头在接受新姿势之前，会先在躯干坐标系内进行检查。

“学习型镜头检查”使用在模拟器中训练的 Q-learning 策略，帮助决定是接受姿势、保留旧姿势，还是补偿视角。在开启之前，会与几何方法做比较。如果人被遮挡、不确定是否是同一个人，或无法区分人的旋转与摄像头的旋转，就会保留最近一次可靠的姿势。模拟器的结果并不能证明在真实片段上的准确度。

按真实姿势检查手板、关节球、手臂杆、躯干和头部，包括耸肩抬升。每个部件之间必须至少相距 10 毫米（为舵机齿轮间隙留出余量；可在 safe_path.json 中以 clearMm 加上骨架的余量设置）。会发生碰撞的目标姿势会先寻找附近的无碰撞姿势，然后用 RRT* 寻找绕行路径，圆角处理之后再次检查碰撞和时间。预览、项目和导出的命令使用同一套已检查的姿势。当机器人跟不上时，“配合音乐”可能会减小运动幅度。关闭后，会保持姿势并增加时间去移动或绕行，预览视频也会放慢到机器人的节奏。重复的姿势不会压缩或倒回音乐的时间。

3D 画面质量会根据打开网页的设备自动选择。可在 中心 → 设置 → 3D 画面 中更改。节能模式会降低帧数和分辨率，同时保持相同的播放节奏和碰撞检测。重新加载页面后，边缘效果会采用新值。

Nong Studio —— 使用指南与每个调整点的详细说明

Nong 人形机器人（10 个舵机关节）的 3D 模拟器和动画姿势设计器。在电脑上运行，采用按需 3D 渲染，省电、占用资源少，不会卡住。

当前 Nong Studio 界面概览（当前真实界面） 概览
第 1 点：调整 10 个舵机关节角度的面板（关节滑块与检查器） 关节控制
1 左臂滑块（L_SH_P、L_SH_R、L_EL_P、L_EL_R）
如何设置： 拖动滑块或输入角度（该关节设定的范围；HOME 和零点可能不同）。
机器人会发生什么变化： • L_SH_P / L_SH_R: 左肩前后弯曲（俯仰）并向外、向内摆动（侧摆）。
• L_EL_P / L_EL_R: 左肘弯曲，前臂旋转。
舵机立即转到真实角度，并有限位，绝不会撞到机器人的框架。
2 右臂滑块（R_SH_P、R_SH_R、R_EL_P、R_EL_R）
如何设置： 拖动滑块或按 镜像 按钮，从左臂复制姿势
机器人会发生什么变化： 独立控制右臂的 4 个轴。按“镜像”后，右臂会立即展开成与左臂对称的姿势。适合做合十礼、抱臂或同时举手。
3 腰部和耸肩滑块（WAIST 与 SHRUG）
如何设置： WAIST 左右转动 / SHRUG 调整四连杆机构
机器人会发生什么变化： • 腰部： 腰部扭动，让机器人看向一侧，±30°。
• 耸肩： 肩梁倾斜，一侧升起，另一侧下降，总共 26°，模仿人类耸肩。

如何设置： 点击下方的 Home、Relax 或 Zero Lock 按钮

• 放松： 停止发送舵机控制脉冲；并不会切断供电，释放多少保持力取决于舵机。
• 零位锁定： 锁定零点坐标，防止有人不小心移动位置。

6 动作平滑不抖动（不停顿地通过关键帧）
如何设置： 无需操作，所有动作都会自动应用此功能：Studio 中的动作组、视频生成的动作、Studio 找到的绕行路线、说话时的动作、RL 生成的动作以及 Shows。如果关节继续沿同一方向运动，机械臂会直接经过关键帧，不会在每个关键帧都停下。关节反向时（甩动动作）、有停顿（hold）时，以及动作开始和结束时，仍会准确停在对应的关键帧位置。所有动作的时间安排都不变，所以仍能与音乐同步。可以在文件中按动作来源分别开启或关闭此功能 motion_smooth.json (sources) 在 Studio 外部制作的动作文件（如 RL）使用 python tools/smooth_sequence.py ไฟล์.yaml 平滑处理绝不会让动作比原来更顿挫卡顿：任何在平滑曲线上比“每帧停顿”更颠簸的关键帧，都会被系统自动降速（jerkGuard）对于从每秒 50 次采样压缩而来的 RL 动作，机械臂会以原动作的速度穿过各个关键帧，并保持在已通过防碰撞检查的原轨迹上（followDensePath)
机器人会发生什么变化： 导出的文件中会包含这一行 pass: 动作前（该动作的起始与结束速度）。升级了新固件的机器人会将其作为指令接收 PASS 旧版机器人会跳过此行并以传统方式运行（每帧停顿）。Studio 会在平滑后的轨迹上以相同的安全距离检查防碰撞。如果平滑曲线会导致碰撞，该动作将自动回退到经过验证的直线轨迹并在关键帧处停顿。机器人自身也会进行二次安全校验：如果速度超出舵机极限或时间被拉长，将按传统方式播放。在 4 套欢呼动作中，动作途中的停顿从 226–429 次大幅减少至 35–101 次（尚未在真机上实测）。
7 撤销 / 重做（误点也不会丢作品）
如何设置： 点击时间条里（缩放按钮旁）的 ↶ Undo，或按 Ctrl+Z，撤销最近一次修改，例如误删的关键帧。点击 ↷ Redo 或按 Ctrl+Y 恢复。可以连续撤销多步。一次连续的拖动或输入算作一步。打开文件或演出后会重新开始记录。
机器人会发生什么变化： 机器人不会改变，只撤销屏幕上时间线里的动作。如果已经保存到机器人，需要再保存一次。
8 更换屏幕颜色（深色模式）
如何设置： 在 Studio 顶部栏的颜色框中选择一套配色，例如 Midnight 就是深色模式，长时间使用更护眼。3D 画面的背景也会一起变化。它与 Hub 其他页面使用同一套配色，在任何页面选择都对所有页面生效。
机器人会发生什么变化： 不会改变机器人，也不会改变动作文件，只改变这台电脑上的屏幕颜色。
9 保存前会询问是否替换同名文件（两个标签页不会互相覆盖）
如何设置： 点击 Save 时，Studio 会向 Hub 询问这个名字是否已被使用。如果另一个标签页或另一个人刚保存了这个名字，会弹出窗口询问是否替换。点击取消并输入新名字即可保留两个文件。
机器人会发生什么变化： 不会改变机器人。点击取消后，原有文件保持不变。
10 几乎看不到人的视频（用文字说明）
如何设置： 点击 Make moves 后，如果 Studio 只在不到四分之一的视频中看到人，会先提示“几乎看不到人”，并建议使用能看到整个人（包括手臂）的视频。详细数字（短暂反转、不确定的时刻）放在“Show technical details”之后。
机器人会发生什么变化： 不会改变机器人。这只是在把动作放到时间条之前帮助你判断的提示。
11 场馆内网的视频链接(例如 NAS)
如何设置： 互联网链接和所选文件照常可用。指向您网络中设备(NAS 或另一台电脑)的链接出于安全会先被拒绝。1) 在机器人标签登录。2) 把该设备的视频链接粘贴到“或链接”并按获取。3) 出现“这是您网络中的设备”时,按“允许此设备”。4) 再按一次获取。要查看或撤销名单,请打开链接框下方的“我的网络中可提供视频的设备”;也可以自己输入名称或地址(例如 nas.local 或 192.168.1.50),或按移除。本机自身和云端地址始终被拒绝,无法允许。
机器人会发生什么变化： 不会改变机器人,只决定 Hub 愿意从哪些设备获取视频。名单只保存在这台电脑上。
第 6 点：编排演出与音乐同步 演出与音乐
1 绑定演出配乐（演出音乐同步）
如何设置： 选择音乐文件来源： /music/song.mp3 在 SD 卡中
机器人会发生什么变化： 音乐和机器人的动作会在节拍上准确地同时开始，按下停止时系统会自动关闭声音。
2 暂停间隔
如何设置： 设定动作之间的暂停时间，例如 pause: 2.0s
机器人会发生什么变化： 机器人会在设定的时间内保持一个优美的姿势，然后才开始下一个动作。
3 将演出发送到开发板（保存到机器人）
如何设置： 按 💾 保存到机器人
机器人会发生什么变化： 演出会保存到机器人自己的 SD 卡，因此机器人开机后无需连接电脑，就能自己表演这场演出。
第 7 点：说话时手臂的动作（说话时的动作） 序列
1 试一个句子（▶ 显示）
如何设置： 输入机器人要说的句子，选择说话风格（亲切、礼貌……），然后按 ▶ 显示
机器人会发生什么变化： 此页面用与“语音”页面相同的声音说出句子，3D 画面中的手臂会随声音运动。这只是预览；真实机器人不会动。动作会保留在时间条上，可按播放再看一遍（没有声音）。如果没有登录，则只能看到动作，没有声音。再短的句子也至少会有一个动作。
2 为还没有动作的词创建新动作
如何设置： 输入表示方向或身体部位的词，例如“在右边”“上面”“心”，然后按显示。勾选 让 AI 想出新动作 如果希望在没有任何规则匹配时，由与“语音”页面相同的 AI 来想出动作（需要登录）。
机器人会发生什么变化： 生成的动作会根据机器人的尺寸和关节限位进行调整，并检查不会撞到自身（必要时寻找绕行路径）。无法做到安全的动作会给出原因，且不会被使用。按 ＋ 保留 将其保存为永久动作，“语音”页面就会对该词使用这个动作。所有词和规则都在 config/gesture_makers.json
3 手臂的休息姿势（手势之间的手位）
如何设置： 选择 手势就绪 （肘弯曲，手在身前）或 站直（原位） （站直，手臂放下）
机器人会发生什么变化： 说话时在动作之间，手臂会回到这个姿势休息。准备姿势可以更快动起来；站直姿势看起来更安静。
4 动作列表与事件
如何设置： 修改调用每个动作的词，按 ▶ 查看单个动作，或自己在时间条上编排动作，然后按 ＋ 保存为手势 取消勾选“事件”即可关闭该事件的动作。
机器人会发生什么变化： “语音”页面根据所说的词挑选动作，并用随机的小动作填补空隙。

3D 画面静止时会停止绘制，并在编辑器或监视器中的姿势变化、打开/关闭网格或手部标记、加载更多模型、或调整屏幕大小时重新绘制。

如果无法读取已保存的项目列表，Studio 会保留之前的选择，并同时在状态栏和中央通知栏显示错误，因此从每个标签页都能看到。按“重试已保存的动作”可再次尝试读取。页面上的作品会保留。

机器人姿势训练图片（电脑上的实验）

生成姿势视图可使用 python -m tools.robot_pose synth --n 20000 --no-images --out ABSOLUTE_PRIVATE_PATH，然后渲染 python -m tools.robot_pose.render_mujoco ABSOLUTE_PRIVATE_PATH/views.jsonl --out ABSOLUTE_PRIVATE_PATH。MuJoCo 使用 Studio 的骨架和已保存的相机设置，并随机调整光照、颜色、纹理、模糊和噪点。标注会根据深度信息，标出被其他部件挡住的关键点。对于位于自身外壳内部的关节中心，会根据骨架尺寸留出判断余量。所有图片、标注和报告都应保存在 PC 的私有位置： .local/robot_pose 文件夹，使用完整路径。这些是模拟图像；真实视频的标注仍需要另行观察机器人保持静止的姿态，并人工检查画面。如果有私有的网格模型，也可以选用 CAD 外观；它使用同一套关节结构，并核对源模型中各部件的安装偏移。CAD 中不存在的参考点，包括虚拟底座点，都不会标注。用于训练的视角必须至少能看到三个关节；完全被遮挡的视角会被剔除。未标注的底座点仍可用来确定机器人立柱的范围。此工具不会启动训练、拍摄，也不会向机器人发送命令。

对于已录制的静止画面， python -m tools.robot_pose.lab_labels ABSOLUTE_MANIFEST.json --out ABSOLUTE_PRIVATE_DATASET 根据独立测量的关节中心位置和已知的静止姿态，估算相机参数。私有清单会指定机器人已停稳的时间段、验证过的参考点、机器人范围、按整个视频划分的训练集和验证集，以及实际观察后可接受的姿态。收到命令确认，并不代表机器人已经到达指定姿态：仍在移动或姿态明显不对的画面会被剔除。只有验证过的参考点才会标注。训练前，至少检查 50 帧叠加了标记的画面；仅凭一个平面内的单一姿态，无法完成基于实际尺寸的相机标定。

恢复未保存的作品时，Studio 会等音乐准备好后才播放或保存。如果无法恢复音乐，请重新打开已下载的 .nong.json 文件。动作仍保留在屏幕上。

选用的作品文件位于 mice_system 内的 results 文件夹。打开 results/index.html，或中心主页 → 最新作品。带动作和音乐的文件在 results/bundles 中。不会自动创建桌面图标。
