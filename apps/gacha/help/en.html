The real mechanism: 1 Hall sensor and 4 magnets

The receive point (Receive) and the drop point (Drop) are on the same side. The Hall sensor is fixed at the receive point only; all 4 magnets are attached to the rotating wheel. The drop side has no Hall sensor.

The Hall sensor says a magnet is at the receive point. This signal does not measure whether the item has fallen out of the chute, and does not measure whether the wheel is exactly centred on the magnet.

Number of slots turned per giving (drop)

This value sets how many slots the machine turns in one giving. drop = 1 is one slot, and drop = 2 is two slots. Choose according to the mechanism and the machine's real dispensing test.

The number of magnets alone does not tell the distance from the receive point to the drop point. So this picture cannot be used to conclude that it must be set to 1 or 2, and it does not say that 2 is used only when loading the first time.

Set up and test the machine's mechanism

Open Machines and kinds then look at the machine you want. The test and tuning buttons really turn the motor, so check the area and be ready to catch the item before you use them.

  • Speed and turning direction: Used to set how the motor is driven.
  • Rock back-and-forth range and entering the Hall: Used to adjust the stop after turning. You need to watch the real stop as well.
  • Rest time: The wait after each turn
  • Number of slots / number of magnets: Set to match this mechanism, which has 4 slots and 4 magnets.
  • Auto Detect / Estimate Hall Advance: Estimates the distance across the Hall band. It does not measure the weight of the prize.
  • Test 1 Pocket, Test 4 Pockets / Test All Pockets: Tests one slot at a time and shows the result when the machine stops. The Hall signal alone does not confirm the accuracy of the stop point or that the prize fell.
  • Drain Machine (hidden under "Rarely needed" and it asks you to confirm first): used to turn the machine round to dispense everything out. Be ready to catch the items and watch it work.

If the status or the buttons do not load, fix the app page first. Do not change the machine's own values to fix the screen.

The contract of the fix set A47-20 that must be checked together before use:

  • GCALIB Scans the Hall strip with a 5-second timeout, reverses for half the measured time, and checks the Hall sensor while stopped. Saves advance only on success. Acknowledges with OK calibrating This isn’t the final confirmation of success. See G? motion_result as done / jam / stopped
  • GTEST 1 or GTEST 4 Test channels one by one; check test_done / test_total and the final result from the board
  • GNUDGE <pwm> <ms> accepted when the machine is free, 1–1000 ms, runs without blocking and can be cancelled with STOP
  • GDRAIN [<max>] no more than 999 times, and it stops when it reaches the limit, the items run out, the event is closed, it jams or STOP is pressed. The web page must have a positive stock that was counted; if the stock is not counted, a max must be given.
