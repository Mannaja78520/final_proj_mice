🎮 All-Jao Games — mini-games and automatic prize giving

Play event games through Mice. The games available may change with the installed version and event settings.

Open the games from Mice

In Tools, open All-Jao Games and choose Open in a new tab.

Choose a game

On the first screen, continue to the game list. Choose the wheel, picture matching claw game or quiz as available. The game lobby uses All-Jao’s own Thai interface and colors.

No hub sign-in needed on this PCnew

The games have their own login, so opening them on the PC that runs Mice asks for nothing. Opened from another device on the network, the hub asks you to sign in first, so nobody on the venue WiFi can start programs on this PC.

A win gives a real prizenew

Played inside the hub, a win in the wheel, claw, quiz or memory game can make a prize machine give a prize and tells the player where to collect it. Which result gives what is set on Prize machines ▸ Games that give a prize. For the quiz, fill Score from to give a prize only from that score up (every finished quiz round counts as a win result; write a number or a percent such as 80%; the game says its top score, so more questions need no change; a wheel slice that says “try again” never gives a prize). The player's name typed in the wheel or claw game is used for the per-person limit. The games now keep their data in their own small server (Node, started by the hub with the Open button); play them from the hub so a win reaches the prize machines.

The open-game button opens the tab first, before checking readiness, so the browser does not block it after waiting for the network. If the tab cannot open, allow pop-ups and press it again.
