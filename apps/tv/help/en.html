Old TV / browser: The Home, Studio, Voice and other pages are built to run on an older Chrome / Android WebView (about Chrome 75 and above). The hub sends an older script (converted at build time) to a browser older than Chrome 80 by itself, so the TV side needs no extra work. Features an old browser lacks are filled in automatically. If it still does not open, a red bar says in plain words that the browser is too old: update Chrome or Android System WebView, or open it on a newer computer or phone. If the 3D page does not work on a machine whose graphics card does not support it, Studio still lets you use the sliders and the timeline.

📺 TV Remote & Monitor — a control screen for smart TVs and phones

A very thin control and status web page (a thin client), designed around a centralised server. This page has no 3D renderer. How fast the status shows depends on the network and the device used.

When the tab is hidden, this page pauses asking for status and checks again when the tab is opened. If the browser does not let it remember the mode, the page still opens, choosing the mode by the screen size.

Point 1: the main control buttons and the move player (Remote & Sequence Launcher) Remote Buttons
1 Main control buttons (Restart selected, Stop, Home)
How to set it: Press the large touch buttons on the screen, or press them with the TV remote
What changes on the robot: • Restart selected: Restarts the clip last chosen from the beginning; a clip must be chosen first.
• Stop: Stops the show the hub is playing.
• Home: Stops the show, then sends HOME to the chosen Nong. It uses the pose the board saved and does not set every joint to 90°.
• Mute all speech: The small button in the quick speech box immediately stops all speech currently playing.
2 Move list (Sequence Launcher)
How to set it: Choose a Nong from the Robot list, then press a clip-name button; if there are several machines you must choose the target first.
What changes on the robot: The system pulls motion files from the central Hub (/api/list?kind=sequences) and immediately triggers that motion sequence on the robot. Backstage staff can easily select shows from their mobile phones.
Point 2: the 10 servo joint angle gauges (10-Joint Monitor Gauges) Joint Gauges
1 CSS Light Gauges
How to set it: Watch the blue-green level bars that move with the servo's real angle.
How the system works: It shows the real position of all 10 servos with light CSS gauges, updating every 200 ms without loading the TV's GPU or CPU.

Decoupled architecture: how does it stop the TV freezing?

In the old architecture, opening a 3D page (Three.js) in the web browser of a smart TV or an older phone made the browser compile WebGL shaders and run a calculation loop 60 times a second, which a smart TV's processor is not designed for, so the TV browser closed itself or the machine froze.

Point 3: switching between the two modes (Mobile Remote vs Stage Display) Dual-Mode
1 📱 Mobile Controller mode
How to use: Good for staff or the person driving the robot, holding a smartphone.
What it can do: Extra-large touch buttons, easy to press with a thumb. It has an emergency stop button ⏹ STOP, the 🏠 HOME start pose, large touch move tiles, and a quick button for a greeting, while hiding the technical servo information to save screen space.
2 📺 10-foot stage display mode
How to use: Shown on a large TV screen on the stage for the audience and the organisers.
What it can do: Shows the current show's name (Now Playing) and the progress bar in extra-large text, clearly visible from 3-5 metres, with the 🟢 PLAYING status.

If playing, stopping or speaking fails, a message appears under the top bar. HOME is sent on only after the stop was answered successfully and the robot confirmed STOP with no error. If stopping the earlier job fails, the system still tries to send STOP to the chosen robot and reports the combined result. Pressing Stop or changing the robot while the list is loading cancels a start that is still waiting, including a play or HOME request already sent that reaches the hub late. The text you typed stays if speaking fails.

The Refresh button shows "Refreshing…" while loading, then says the time of the last update, or that it cannot reach the hub.
