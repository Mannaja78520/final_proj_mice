📷 Cameras — กล้องทุกตัวในที่เดียว ใช้พร้อมกันได้หลายหน้าจอและหลายโปรแกรม

หน้านี้รวมกล้องทุกชนิดไว้ด้วยกัน ได้แก่ บอร์ดกล้อง ESP32-CAM กล้อง USB ของเครื่องนี้ และกล้องเครือข่ายที่คุณเพิ่มเอง ระบบดึงภาพจากกล้องแต่ละตัวเพียงครั้งเดียว แล้วแจกต่อให้หลายคนและหลายโปรแกรมดูพร้อมกัน ทั้งหน้านี้ หน้าต่างดูแยก และแอปจำใบหน้า

จุดที่ 1: กล่องแสดงภาพสดจากกล้อง ESP32-CAM (Live Stream & Relay) ภาพสด
1 กล่องภาพสดและการกระจายสัญญาณ (Multi-Client Relay)
ปรับอย่างไร: เปิดดูผ่าน /app/camera จากเบราว์เซอร์กี่เครื่องก็ได้พร้อมกัน
ระบบเปลี่ยนไปยังไง: ชิป ESP32 มีแรมจำกัดส่งได้แค่ 1 สตรีม Hub ส่วนกลางจึงเป็นตัวดึงภาพมา 1 สตรีม แล้วนำมากระจายต่อให้คนดูหลายคนพร้อมกันโดยบอร์ดไม่ล่ม
2 แหล่งรับสัญญาณ WiFi vs USB
ปรับอย่างไร: ตรวจสอบให้แน่ใจว่าบอร์ดต่อ WiFi (ไฟสถานะเขียว)
ระบบเปลี่ยนไปยังไง: สาย USB / RS485 รองรับเฉพาะข้อความและคำสั่งตัวอักษร ไม่สามารถส่งไฟล์ภาพ JPEG ได้ หากต่อเฉพาะสาย ภาพจะไม่ขึ้นแต่สามารถตั้งค่าเซนเซอร์ได้
เพิ่มกล้องเครือข่าย

กด Add a camera แล้วเลือกชนิดกล้อง ใส่ชื่อและลิงก์ จากนั้นกด Add

หากต้องปรับภาพจากบอร์ด ให้เปิด Settings ที่การ์ดของกล้อง ESP32-CAM

นี่คือบอร์ดกล้องรุ่นไหน

โมดูลตรวจหาบอร์ดกล้องของตัวเองตอนเปิดเครื่อง โดยลองรูปแบบการต่อสายที่รู้จักทีละแบบจนกว่าเซ็นเซอร์จะตอบกลับ บอร์ดเลียนแบบที่ไม่ทราบรุ่นจึงมักใช้งานได้ทันที รองรับบอร์ด ESP32-CAM รุ่นดั้งเดิม (AI-Thinker, ESP-EYE, M5Stack, TTGO T-Journal, WROVER) และบอร์ด ESP32-S3 (Freenove / ESP32-S3-EYE, XIAO S3 Sense, FireBeetle S3, S3-CAM) ที่ใช้เซ็นเซอร์ OV2640, OV3660 และ OV5640 บอร์ด S3 ต้องใช้เฟิร์มแวร์รุ่น S3 โดยเฟิร์มแวร์รุ่นดั้งเดิมและรุ่น S3 จะลองเฉพาะบอร์ดที่ใช้ชิปตรงกับรุ่นของตัวเอง หากทราบรุ่นบอร์ด คุณเลือกเองได้ด้วย CAM BOARD <name> (or CAM BOARD AUTO) แล้วรีสตาร์ตโมดูล ผังขาของบอร์ด S3, WROVER และ T-Journal อ้างอิงจากตารางของผู้ผลิต และยังไม่ได้ทดสอบกับบอร์ดจริง

หลายคนดูพร้อมกันได้

ตัวบอร์ดเองถูกอ่านได้ทีละอย่างเท่านั้น และนั่นเป็นข้อจำกัดของฮาร์ดแวร์ ไม่ใช่ที่ใครเลือกไว้: มันมีเฟรมบัฟเฟอร์เดียว และการเอาเฟรมจะเรียกคืนเฟรมที่ให้ยืมไปแล้ว สองสตรีมจึงจะฉีกภาพของกันและกัน Hub จึงถือ หนึ่ง การเชื่อมต่อต่อกล้องแต่ละตัว แล้วป้อนผู้ชมทุกคนจากมัน เปิดหน้านี้บนกี่จอก็ได้

เมื่อการค้นหาล้มเหลว จะแจ้งให้กด Look again แทนการบอกว่าไม่มีกล้อง ข้อมูลที่เก็บไว้จะระบุว่าอาจเก่า; หากค้นหาได้บางส่วน อาจมีกล้องที่ยังไม่แสดง

เพิ่มกล้องที่ไม่ใช่บอร์ด ESP32

กด “เพิ่มกล้อง” แล้วเลือกชนิด: กล้องเครือข่ายหรือลิงก์วิดีโอ (ที่อยู่ที่ขึ้นต้นด้วย http หรือ rtsp จากกล้อง IP หรือแอปกล้องในมือถือ) หรือกล้องตัวอย่างที่ไม่ต้องมีอุปกรณ์จริง ต้องเข้าสู่ระบบก่อน กล้อง USB ของเครื่องนี้ไม่ต้องเพิ่ม มันขึ้นมาเอง

ลิงก์ที่มีรหัสผ่านของกล้องจะถูกเก็บไว้บนเครื่องนี้เท่านั้น และไม่แสดงบนหน้าเว็บ ที่อยู่ของเครื่องนี้เอง (127.0.0.1) และไฟล์ในเครื่องใช้เป็นลิงก์ไม่ได้

ช่องในหน้าเพิ่มกล้อง: Add a camera = เพิ่มกล้อง, Kind = ชนิดของกล้อง, Link = ลิงก์ของกล้อง

เปิดดูในหน้าต่างแยก

กด “เปิดในหน้าต่างแยก” ที่การ์ดกล้อง จะได้หน้าเต็มจอที่มีแต่ภาพสดของกล้องตัวนั้น เหมาะกับจอที่สอง ทีวี หรือมือถือของคนอื่น เปิดกี่หน้าต่างก็ได้ กล้องไม่รู้สึกอะไร และถ้าภาพหลุดหน้านี้จะต่อใหม่เอง

ใช้กับการจำใบหน้า

ติ๊ก “จำใบหน้าด้วยกล้องตัวนี้” แอปจำใบหน้าจะเริ่มใช้กล้องตัวนั้นภายในไม่กี่วินาที โดยไม่ต้องรีสตาร์ต และเลิกใช้เมื่อเอาติ๊กออก กล้อง ESP32-CAM ใช้ได้เหมือนกล้องปกติ และใช้พร้อมกับการดูสดหรือการอัดวิดีโอได้

ใช้กล้องแต่ละตัวผ่านทางเดียวเท่านั้น กล้อง USB เปิดได้ทีละโปรแกรม และบอร์ด ESP32-CAM รับได้แค่หนึ่งการเชื่อมต่อ ถ้า hub เปิดกล้องอยู่แล้วแล้ว Face_Regonize พยายามเปิดกล้องตัวเดียวกันเอง จะขึ้นว่ากล้องถูกใช้อยู่ หรือภาพดำ ให้ใช้กล้องผ่านสวิตช์ในหน้านี้ แล้วให้ Face_Regonize รับภาพจากลิงก์ของ hub แทน (รอฝั่งเพื่อนทำ)

ลิงก์สำหรับโปรแกรมอื่น

เปิดสวิตช์รายละเอียดทางเทคนิคเพื่อดูลิงก์ภาพสดของกล้องแต่ละตัว โปรแกรมอื่นในเครือข่าย เช่น โปรแกรมอัดวิดีโอหรือแอปของเพื่อน ใช้ลิงก์นี้ได้เหมือนกล้องเว็บแคมทั่วไป (MJPEG) ระบบยังคงอ่านกล้องจริงครั้งเดียว
