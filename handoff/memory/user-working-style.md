Replies in Thai when the user writes Thai; short. User is on Windows PowerShell.
Users of the products are non-engineers (business/art staff): plain words, simple screens.
No questions for choices that can be switched later: decide, say which, continue. Ask only for the robot, the user's own accounts, or irreversible steps.
Never promise what needs the user; say what needs them.

**Why:** the user is often away; a waiting thread is a stalled thread.
**How to apply:** pick the reading that does not destroy running work.
